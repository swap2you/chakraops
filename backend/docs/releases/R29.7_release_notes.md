# Release R29.7 — Integrity Export Pack v1

**Date:** 2026-02  
**NO GIT.** Manual-only.

**Goal:** Add a manual "Download integrity bundle" action when integrity status is Review. Bundle helps debugging integrity drift without manual copy/paste. All export content is sanitized (no FAIL/WARN/PASS or FAIL_/WARN_), deterministic, and contains no secrets.

---

## User-visible changes

- **Positions page — Integrity (when Review):** New button **"Download integrity bundle"** downloads a ZIP file containing sanitized JSON snapshots: manifest, last integrity check result, reconcile diff, positions from DB, computed positions, and a subset of system health (rebuild, reconcile, integrity check blocks only).
- **System Diagnostics — Integrity Check card (when Review):** Same **"Download integrity bundle"** button; download uses include_paper=true (no symbol filter on Diagnostics page).

## API / backend

- **GET /api/ui/positions/unified/integrity-bundle**
  - Query: include_paper (default true), symbol (optional), limit (default 200, max 1000).
  - Response: application/zip; filename integrity_bundle_<utc_ts>.zip.
  - Zip contents: manifest.json, integrity_check.json, reconcile_diff.json, positions_db.json, positions_computed.json, system_health_subset.json. All JSON sanitized; no decision_latest write; no secrets.

## Tests and evidence

- Backend: test_r297_integrity_bundle.py — expected files in zip; no forbidden tokens in zip JSON; deterministic for fixed fixture; no decision_latest write.
- Frontend: PositionsPage and SystemDiagnosticsPage — Download button only when Review; click calls download with correct params; no forbidden tokens in document.
