# Release R23.4.5 — Targets/Exit Plan Validity + S/R Hardening + Universe Shares Consistency

**Date:** 2026-02  
**Goal:** Valid monotonic targets (T1 < T2 < T3); S/R selection with minimum distance and epsilon; Universe Shares column aligned with Symbol Diagnostics Shares tab; UI tooltips and "target already exceeded" badge.

---

## Scope

- **In scope:** build_exit_plan_v235 (request-time); MIN_TARGET_DISTANCE_PCT / TARGET_EPS_PCT; swing_cluster supports_ordered/resistances_ordered; universe shares_eligible via same request-time technicals + mtf_levels as symbol-diagnostics; target_basis, level_source_timeframe, distance_to_t1_pct, targets_already_exceeded in API; tooltips and badge in Symbol Diagnostics page.
- **Out of scope:** Decision artifact persistence changes; TradingView-style UI.

## API changes

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/ui/symbol-diagnostics?symbol=` | exit_plan and targets include target_basis, level_source_timeframe, distance_to_t1_pct, targets_already_exceeded. |
