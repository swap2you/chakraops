# R30.7 — Runtime-File Hygiene Cleanup

## Title

R30.7 — Runtime-file hygiene cleanup

## Goal

Stop tracking three grandfathered runtime output files that were previously committed as known debt, while preserving the physical files locally and leaving Git history intact.

## Scope

- Untrack exactly these three files from the Git index:
  - `out/decision_latest.json`
  - `out/mark_refresh_state.json`
  - `out/notifications.jsonl`
- Confirm `.gitignore` already covers `out/` (it does — `out/` and `*out/*` are present).
- Preserve all three files physically on disk; they must continue to exist locally after the index removal.
- Update release documentation (`R30.7_requirements.md`, `R30.7_release_notes.md`, `RELEASE_CHECKLIST.md`).
- Update governance docs (`docs/master/KNOWN_ISSUES.md`, `docs/master/CURRENT_STATE.md`).
- Record local verification evidence in `out/verification/R30.7/notes.md`.

## Non-Goals

- No trading logic changes
- No UI changes
- No ORATS changes
- No database changes
- No scheduler changes
- No GitHub Actions changes
- No brokerage integration
- No deployment changes
- No Git-history rewrite
- No legacy-doc cleanup
- No other files under `out/` or `data/` touched

## Acceptance Criteria

1. `git ls-files out/` returns empty (no tracked files under `out/`).
2. All three files physically exist on disk after the operation.
3. `git check-ignore -v out/decision_latest.json out/mark_refresh_state.json out/notifications.jsonl` reports all three matched by `.gitignore`.
4. Backend gate passes: `cd chakraops && python -m pytest tests -q --tb=short`.
5. Frontend tests pass: `cd frontend && npm run test -- --run`.
6. Frontend build passes: `cd frontend && npm run build`.
7. `git status --short` is clean except for the index removals and new documentation files staged for this release.

## Verification Path

`out/verification/R30.7/notes.md`

## Rollback

Tag `chakraops-r30.6.1` is the rollback point.

To roll back R30.7:
- Re-add the three files to the Git index only if explicitly approved by the operator: `git add -f out/decision_latest.json out/mark_refresh_state.json out/notifications.jsonl`.
- Otherwise, revert the R30.7 commit.

Existing Git history is **not** rewritten as part of this release or its rollback.

## Explicit Note

This release does not rewrite existing Git history. The three files will remain visible in prior commits. Only future tracking is stopped.
