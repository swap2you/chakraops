# R27.2 — Paper portfolio realism + close workflow parity

**Branch:** release/R27.2  
**Manual-only.** No broker automation. SHARES/CSP/CC only.

## Objectives

- Paper positions: real-time mark/unrealized everywhere; optional include_marks; single-position detail endpoint.
- Close workflow parity: dedicated POST /paper/close with journal action CLOSE_CSP/CLOSE_CC/SELL.
- Journal/Reports: Paper-only filter, Paper badge; split Live/Paper totals when include_paper.

## Non-negotiables

- Decision artifacts code-only; no FAIL_/WARN_ in decision or UI.
- Determinism: fixed mark order; "—" when quotes missing.
- Full gates pass; evidence in out/verification/R27.2/notes.md + UAT.

## Scope

1. **Paper positions:** GET /paper/positions include_marks (default true); GET /paper/positions/{id}; Open tab Entry/Mark/Unrealized/As-of; Closed realized + timestamps; Refresh marks; symbol + strategy filter.
2. **Close workflow:** POST /paper/close (position_id, close_price|close_premium, close_fees, ts); journal is_paper=true, action CLOSE_CSP|CLOSE_CC|SELL; Close button + modal on PaperPage.
3. **Journal:** Paper only filter; Paper badge on is_paper entries.
4. **Reports:** When include_paper, split summary (Live totals + Paper totals).
5. **Tests:** test_r272_paper_close_workflow.py; frontend close modal, paper-only filter, no FAIL/WARN.
6. **Docs:** R27.2_requirements.md, R27.2_release_notes.md, RELEASE_CHECKLIST, out/verification/R27.2/notes.md.
