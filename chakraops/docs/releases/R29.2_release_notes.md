# Release R29.2 — Stored vs Computed Compare v1

**Date:** 2026-03  
**NO GIT.** Manual-only.

**Goal:** Compare mode on Positions when a symbol is selected: Stored vs Computed lists, diff summary and details, all with safe labels. No new APIs.

---

## User-visible changes

- **Positions page — Compare panel (when symbol filter set):**
  - Heading "Compare"; button "Compare stored vs computed" toggles panel open/closed.
  - When open: two columns (Stored list from DB, Computed list from sources) with same symbol and include_paper; diff summary (missing_in_stored, extra_in_stored, mismatched); diff details list (Missing/Extra/Mismatch, id, type, fields_diff); "View diff in diagnostics" link to /system; "Rebuild unified positions" (same confirm modal).
  - All displayed values sanitized (no FAIL/WARN/PASS or FAIL_/WARN_).
  - Data for compare is fetched only when the panel is opened.

## API

- No new endpoints. GET /api/ui/positions/unified and GET /api/ui/positions/unified/db both support symbol and include_paper (confirmed parity). Reconcile-diff used for compare diff summary/details.
