# Release R23.4.2 — Copilot key parsing + auth diagnostics + non-500 failures

**Date:** 2026-02  
**Goal:** Robust Copilot API key parsing, deterministic 503/502 (no 500 for config/auth), system-health Copilot status, and clear runbook for key configuration.

---

## Scope

### Key handling (backend)

- **Env:** **COPILOT_OPENAI_API_KEY** (preferred) or **OPENAI_API_KEY**. No other sources.
- **Normalize:** strip whitespace; remove surrounding single/double quotes; remove accidental `OPENAI_API_KEY=` or `COPILOT_OPENAI_API_KEY=` if pasted as a full line.
- **Validation:** key must start with `sk-`, length ≥ 20, no spaces/newlines/tabs inside. Otherwise → **COPILOT_KEY_MALFORMED** (503).
- **Responses:**  
  - No key → 503 **COPILOT_KEY_MISSING**.  
  - Key present but malformed → 503 **COPILOT_KEY_MALFORMED**.  
  - OpenAI 401 → 502 **COPILOT_AUTH_FAILED**.  
  - Rate limit/timeout → 503 **COPILOT_UPSTREAM_UNAVAILABLE**.  
  - Other → 500 **COPILOT_INTERNAL_ERROR** (only for unexpected server errors).
- **Startup log:** one line `[COPILOT] enabled=<bool> key_present=<bool> key_format_ok=<bool> model=<name>`. No key value or fragment.

### System health

- **GET /api/ui/system-health** now includes **copilot:** `{ enabled, key_present, key_format_ok, model }` (status only, no secrets).

### Frontend

- Error banner “How to fix” for **COPILOT_KEY_MALFORMED:** “Key looks malformed (quotes/spaces). Fix .env and restart.”

### Tests

- **test_r2342_copilot_key_parsing.py:** normalize (quotes, strip, prefix), validate (valid / internal space / short / empty), endpoint 503 MISSING, 503 MALFORMED.

## How to configure the API key

1. In backend env (e.g. `chakraops/.env`), set **one** of:
   - `COPILOT_OPENAI_API_KEY=sk-your-key-here`
   - `OPENAI_API_KEY=sk-your-key-here`
2. Use a single line; no spaces inside the key. Quotes are optional and are stripped.
3. Restart the backend (e.g. uvicorn). Check startup log for `[COPILOT] ... key_format_ok=true`.
4. If you see **COPILOT_KEY_MALFORMED**, remove quotes/spaces from the key in `.env` and restart.
5. If you see **COPILOT_AUTH_FAILED**, the key is invalid or expired; verify in OpenAI dashboard and update `.env`.
