# R34.0 Requirements — Canonical Live Cutover (closes R33 blocker / H-5)

**Branch:** `release/R31-R35-program` (program milestone 4)
**Risk level:** Level 3 — application refactor and analytical presentation.

## Objective

Close the Claude R33 BLOCKER by making the canonical decision engine the authoritative
producer of the primary live recommendation, with stale-data safety, recommendation-set
capital safety, and a deliberate persistence decision — before any broader product
consolidation.

## Functional requirements (delivered in this pass)

1. The canonical engine produces the **primary** live recommendation surfaced by
   `/api/ui/action-needed` (consumed by Dashboard + Today) and Symbol Diagnostics. (DONE)
2. The live API may use an adapter for backward compatibility, but the canonical engine
   produces the primary decision. (DONE — `legacy_adapter.py` + `live_service.py`)
3. The legacy evaluator/ranking stack must not independently produce a conflicting primary
   recommendation; legacy output is clearly labeled non-authoritative/diagnostic. (DONE)
4. The R32 `stale_data_gate` is enforced on every route capable of returning ACTIONABLE;
   missing/stale critical data yields BLOCKED/WATCH/STAY_IN_CASH, never ACTIONABLE. (DONE)
5. Invalid `profile_overrides` returns HTTP 422, not 500. (DONE)
6. Active profile is carried through the live response; top actionable limited to 5–7;
   manual-only label present. (DONE)
7. Recommendation-set capital safety: per-suggestion-not-additive label, total capital
   required, over-capital warning, profile cash buffer preserved, no assumed leverage. (DONE)
8. A deliberate persistence decision is documented before any DB change. (DONE — RETAIN)

## Non-functional requirements

- No order routing, no broker integration, no auto-trading, no silent data fallback.
- No secrets in logs/evidence; local ORATS `.env` untouched.
- Heavy calculations/jobs remain outside HTTP request handlers (live cutover reads the
  persisted artifact and runs the deterministic engine in-process over a small candidate set).
- R33 strategy mathematics unchanged.

## Acceptance criteria

- Tests prove: canonical authoritative live source, stale-data live-route blocking, no
  conflicting primary, profile carried, manual-only, top 5–7 cap, capital-set warning, 422.
- AGENTS.md baseline gates pass (backend pytest, frontend tests, frontend build).
- Persistence decision recorded before any schema change.

## Out of scope for this pass (STAGED — not claimed complete)

Packet Phases 4–9: full dashboard/navigation consolidation, portfolio/position experience,
universe/data-health UI, backtest engine, journal/retention/reporting, broader
frontend-quality overhaul. These are tracked as remaining R34 scope and must not be claimed
complete until implemented and evidenced.
