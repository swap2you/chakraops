# R29.0 — DB-first Positions default + staleness guardrail

**NO GIT.** Manual-only. No broker automation.

## Goal

- Make Positions page **default to Source: Stored** (source=db).
- When stored DB is **stale** (or rebuild never run), show a prominent **safe-label banner** with primary action "Rebuild unified positions".
- Rebuild uses existing endpoint; include_paper honors current filter. No background jobs; no auto rebuild.

## Non-goals

- No new background jobs. No auto rebuild. No decision artifact or notification changes in read paths.

## Non-negotiables

- Decision JSON artifacts remain code-only. Do not write out/decision_latest.json from these features.
- Never persist raw FAIL_/WARN_ tokens. UI and API use safe labels only (OK/Review/Degraded/Blocked).
- No FAIL/WARN/PASS in API payloads, state files, or DOM.
- Deterministic ordering unchanged. Repo hygiene: out/* runtime artifacts not staged.

## Definition of stale

- Use system-health **positions_unified_rebuild** (and/or unified reconcile block).
- If rebuild block **missing** OR **last rebuild finished timestamp missing** → stale = true.
- Else if **finished_at_utc** older than **6 hours** from now (UTC) → stale = true.
- Else stale = false.
- Banner severity: safe label only (e.g. status="Review", status_label="Stored positions may be stale").

## Scope

### A) Backend (minimal)

- System-health **positions_unified_rebuild** block: ensure **finished_at_utc** (alias of last_rebuild_at_utc) and **include_paper** when present. Safe labels only. No change to DB read endpoint.

### B) Frontend

- **PositionsPage:** Default source = **db** (Stored). Explicit toggle: Source Stored / Source Computed.
- When **source=stored** and **stale=true:** banner (title "Stored positions may be stale", subtext, button "Rebuild unified positions"); confirm modal; include_paper from current filter; button disabled when rebuild running; show "Rebuild running".
- When source=computed, no banner. Reuse rebuild mutation; invalidate system-health, stored positions, computed positions, reconcile-diff. Confirm modal safe copy only.

### C) Tests

- **Backend:** test_r290_positions_staleness_health_contract.py — system-health has positions_unified_rebuild with finished_at_utc; no forbidden tokens in block; endpoint does not write decision_latest.
- **Frontend:** PositionsPage — default source Stored; when stale, banner and rebuild button with include_paper; when rebuild running, button disabled and "Rebuild running"; no FAIL/WARN/PASS in document.

### D) Docs + verification

- R29.0_requirements.md, R29.0_release_notes.md; R29.0 section in RELEASE_CHECKLIST.md.
- out/verification/R29.0/notes.md: gate commands, tail lines, UAT, grep proof.
