# R25.5 — Phase 5 Journaling + Monthly Reporting Baseline (Requirements)

## Scope

SQLite-backed trade journal (manual executions only) and baseline monthly reporting. Single-user; no auto-execution or broker integration. Journal is separate from decision artifacts; notes never persist to decision_latest.json.

## Non-negotiables

- **Decision artifacts remain code-only** — No prose/UI strings or raw FAIL_/WARN_ in decision_latest.json. Journal DB is separate.
- **UI** — Never display raw FAIL/WARN; use safe labels only.
- **No auto execution** — Journal records manual entries only; no broker integration.
- **Gates** — Backend pytest, frontend tests, frontend build pass; evidence in `out/verification/R25.5/notes.md`.
- **out/ is gitignored** — Journal DB stored under `data/` (e.g. data/journal.db), not under out/.

## Requirements

### 1) Journal store (SQLite)

- **Location:** `data/journal.db` (repo-relative; do not store under out/).
- **Record types:** Manual executions only. SHARES: BUY, SELL. OPTIONS: OPEN_CSP, CLOSE_CSP, OPEN_CC, CLOSE_CC, ROLL (optional in v1).
- **Fields:** id (uuid), created_ts, trade_date (YYYY-MM-DD), as_of_ts, symbol, strategy (SHARES/CSP/CC), action (BUY/SELL/OPEN/CLOSE/ROLL), qty, price (shares) or premium (options), fees (optional), contract_key (nullable; required for options), expiry/strike/right (nullable), notes (short, optional), tags (optional), realized_pl (nullable), link_id (nullable; groups open+close).
- **Ordering:** Deterministic by created_ts desc. SQL injection safe (param binding).

### 2) APIs

- **GET /api/ui/journal** — Query: from, to (YYYY-MM-DD), symbol, strategy, limit, offset. Returns list ordered by created_ts desc.
- **POST /api/ui/journal** — Create entry.
- **PATCH /api/ui/journal/{id}** — Update notes, tags, fees, trade_date, qty, price/premium where safe.
- **POST /api/ui/journal/export** — Query: from, to. Returns CSV (text/csv).
- **GET /api/ui/reports/monthly** — Query: month=YYYY-MM. Returns aggregates; safe response only.

### 3) Monthly report (baseline)

- Total realized P/L; by strategy (SHARES, CSP, CC); trade count, win/loss count, win rate; avg hold days; top 5 winners/losers; fees total.

### 4) UI

- **Journal page:** Table with filters (month, symbol, strategy). Add entry modal. Inline edit notes/tags. Export CSV.
- **Reports page:** Month picker, summary cards, winners/losers tables.
- **Navigation:** Sidebar links to Journal and Reports. No FAIL/WARN in UI.

### 5) Safety

- Journal notes never in decision artifacts (separate DB). Validate inputs; safe error messages.
