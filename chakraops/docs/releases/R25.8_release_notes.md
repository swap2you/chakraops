# R25.8 — Cadence Discipline + Earnings Feed Validation

**Date:** 2026-02

## Summary

Cadence discipline: eligibility remains sticky within the day (EOD-biased); intraday runs use last completed daily candle for spot so eligibility does not flip on partial candles. Request-time fields cadence_mode, eligibility_as_of_ts, and eligibility_is_intraday_stale exposed. Earnings debug endpoint and System Diagnostics earnings probe card added (safe fields only).

## What changed

### Backend

- **Cadence:** When EOD_BIASED, universe evaluation uses last completed daily candle close for spot (not live quote) so intraday scheduler runs do not change eligibility. Symbol-diagnostics response includes eligibility_is_intraday_stale (true when last bar date &lt; today ET). System-health includes cadence_mode and eligibility_as_of for banner.
- **GET /api/ui/earnings/debug?symbol=NVDA:** Diagnostics-only endpoint. Returns safe fields: status (OK/Unavailable/Stale), next_date, days, implied_move_pct, as_of. No raw ORATS payload; no secrets in logs; nothing persisted to decision artifacts.
- **Probe symbol:** Config/env for earnings probe (default SPY); system-health or frontend uses it for the earnings probe card.

### Frontend

- **Cadence banner:** Small banner "Cadence: EOD-biased (as of \<date/time ET>)" using system-health cadence_mode and eligibility_as_of (safe labels only).
- **System Diagnostics:** "Earnings probe" card calling earnings/debug for probe symbol (default SPY); displays status, next_date, days, implied_move_pct, as_of with safe labels. Unavailable when fetch fails or invalid nextErn.

### Tests

- Backend: determinism (eligibility stable across two intraday runs with same last daily candle); earnings debug safe schema and no FAIL_/WARN_; decision artifact hygiene (no new persisted fields).
- Frontend: no FAIL/WARN in document; cadence banner and earnings probe card render.
