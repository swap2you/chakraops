# Release R27.5 — Journal-driven backtesting baseline (replay)

**Date:** 2026-02  
**Branch:** release/R27.5  
**Goal:** Deterministic backtest replay from journal entries; summary + trades; export JSON/CSV; manual-only.

---

## Scope

- **Backend:** run_backtest(start_date, end_date, include_paper, paper_only) sources journal via journal_list_range (trade_date ASC, created_ts ASC, id ASC). SHARES BUY/SELL and OPTIONS OPEN/CLOSE/ROLL interpreted; realized_pl from journal or computed. Output: total_realized_pl, total_fees, trade_count, win_count, loss_count, win_rate, by_strategy, per-trade rows, optional max_drawdown_proxy. Persistence: data/reports/backtests/<range>/[live|paper|mixed]/run_<ts>/ (backtest_summary.json, backtest_trades.csv); SQLite backtest_runs in data/backtest.db.
- **API:** POST /api/ui/backtest/run; GET /api/ui/backtest/runs; GET /api/ui/backtest/download (allowlist summary_json, trades_csv).
- **Frontend:** BacktestPage at /backtest (date range, toggles, run, results, download, history); Backtest in sidebar.
- **Tests:** test_r275_backtest_replay.py; BacktestPage.test.tsx; sidebar test.
