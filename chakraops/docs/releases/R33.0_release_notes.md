## Summary

R33.0 delivers one canonical, profile-driven, portfolio-aware **advisory** decision engine. It implements a profile configuration source and a decision input/output contract, wires the R32 stale-data gate into the canonical engine's actionable paths, enforces hard risk invariants in sizing, and produces a deterministic, bounded (top 5–7) recommendation set with explicit blocked / watch / stay-in-cash outcomes. Nothing creates or routes orders; there is no silent fallback provider.

## Scoring (deterministic, documented)

Option score (0–100) = 0.40*return + 0.25*delta + 0.15*dte + 0.20*liquidity. Golden vectors:
- Perfect Balanced CSP → 100.0; edge Balanced CSP → 38.5; covered-call return uses underlying price; share-buy (iv_rank 30, BULL) → 82.0.

## Mandatory invariants (enforced + tested)

- No uncovered covered call (contracts*100 ≤ shares held).
- No CSP reserving more than available cash after the buffer.
- No negative/impossible quantity.
- No action on stale/missing critical inputs.
- No hidden leverage; no automatic order creation/routing.
