# R29.3 — Integrity Check + Advisory v1

**NO GIT.** Manual-only. No broker automation.

## Goal

Provide a manual operator action that runs an integrity check (stored staleness + reconcile diff summary), returns safe-label result (OK/Review only), and optionally creates one advisory notification when Review with strict dedupe. No decision artifact writes.

## Non-negotiables

- Decision artifacts code-only; this release must **not** write out/decision_latest.json (or any decision artifacts).
- Never persist raw FAIL_/WARN_/PASS tokens anywhere in decision artifacts or API/UI/state.
- UI must never display raw FAIL/WARN/PASS words/codes; safe labels only (OK, Review, etc.).
- Determinism: stable ordering and stable IDs.

## Scope

### A) Backend — POST endpoint

- **POST /api/ui/positions/unified/integrity-check**
  - Request JSON: `{ "include_paper": true }` (default true).
  - Response JSON: `ok`, `status` (OK | Review), `status_label`, `include_paper`, `stale`, `reconcile` (status, status_label, missing_count, extra_count, mismatched_count), `checked_at_utc`.
  - If check already running (single-process lock): return `ok: false`, `status: "Review"`, `status_label: "Check already running"`.
  - No FAIL/WARN/PASS tokens in any field.

### B) Implementation

- Single-process lock (threading.Lock) similar to rebuild lock.
- Reuse: `get_positions_unified_rebuild_health()`, `get_reconcile_diff(include_paper, symbol=None, limit small)` for summary.
- Stale logic: no finished_at_utc → Review, "No rebuild recorded", stale=true; age > 24h → Review, "Stored positions may be stale", stale=true; else OK.
- Overall status: Review if stale OR reconcile.status == Review, else OK.
- When overall Review: call `ensure_positions_integrity_advisory_notification()` — create at most one notification of type POSITIONS_INTEGRITY_REVIEW (only if no active NEW/ACKED of that type); safe message only.

### C) System health (optional)

- Read-only block `positions_unified_integrity_check`: last_checked_at_utc, last_status, last_status_label, last_stale, last_reconcile_*.
- Persist state in small runtime file under out/ (gitignored); safe fields only; no FAIL/WARN/PASS. Grep-proof noted in verification.

### D) Frontend

- PositionsPage Integrity strip: button "Run integrity check".
- Confirm modal text: "This will run an integrity check comparing stored positions with authoritative sources and staleness. Manual action. Continue?"
- After success: refresh system-health and reconcile diff; display last check status/label (OK/Review only).
- While running: disable button, show "Check running".

### E) Tests

- Backend (test_r293_positions_integrity_check.py): safe labels only (no forbidden tokens in JSON); dedupe (repeated POST when Review does not create multiple NEW/ACKED); no decision_latest write; determinism (stable shape and summary).
- Frontend: Run integrity check triggers mutation with include_paper true; no forbidden tokens in document; button disabled while running.

### F) Docs + verification

- out/verification/R29.3/notes.md: gate commands, pasted tail lines, UAT checklist, grep proof (decision_latest, FAIL_/WARN_, FAIL|WARN|PASS in out/*.json).
