## Objective

Produce one trusted architecture map, live-data baseline, defect register, and executable blueprint that govern R32–R35.

1. Read-only inventory of backend, frontend, decision engine, persistence, jobs, notifications, ORATS, universe, earnings/events, backtest, reports, and runbooks.

3. Defect/gap register ranked Critical/High/Medium/Low, each Critical/High with an owner release.
4. Exact R32–R35 execution blueprint with file-level targets, without expanding locked non-goals.
5. No product behavior or source changes. Documentation/audit only.
6. Run AGENTS.md baseline gates with evidence under `out/verification/R31.0/`.
