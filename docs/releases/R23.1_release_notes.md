# Release R23.1 — Operator Trust Fix Pack (identity + store loader + delta visibility + price header + date picker)

**Date:** 2026-02  
**Goal:** Fix Trade Ticket contract identity mismatch, eliminate store loader errors, add delta reject transparency, restore always-visible price in Symbol header, and use a date picker for Shares opened date.

---

## Scope

### Part 1 — Contract identity normalization (P0)

- **Canonical format:** `{strike_int}-{expiry}-PUT|CALL` (strike as integer, no trailing .0).
- **Backend:** `normalize_contract_key(strike, expiry, option_type)` in `decision_artifact_v2.py`; used in `evaluation_service_v2` when building selected_candidates and candidates_by_symbol so both share identical contract_key.
- **Loader:** When loading from JSON, keys like `673.0-2026-03-20-PUT` are normalized to `673-2026-03-20-PUT`.
- **Persist:** `candidate_persist` uses the same helper; no prose in artifact.

### Part 2 — Store loader compatibility (P0)

- **GateEvaluation.reason** and **CandidateRow.why_this_trade** remain optional (default None).
- **from_dict:** Uses `dict.get()` for gates and candidates so missing keys (e.g. reason, why_this_trade) do not cause constructor errors.
- Persisted artifact has only `name`/`status` for gates and no `why_this_trade` for candidates; load succeeds.

### Part 3 — Delta reject diagnostics (P1, request-time only)

- **API:** When `sample_rejected_due_to_delta` is present, response includes **delta_diagnostics**: band_min, band_max, best_delta, miss, direction (TOO_LOW|TOO_HIGH|IN_BAND), best_candidate (strike, expiry, bid, ask, etc.).
- **Not persisted** in decision_latest.json.
- **UI:** Symbol Execution Console shows "Delta band (rejected)" card with Best available delta, Distance to band, target band, and closest contract row (safe text only; no raw codes).
- **CSP chain:** Sample entries enriched with strike, expiry, bid, ask, spread_pct for best_candidate.

### Part 4 — Symbol header price (P1)

- **Header:** Price (spot) always shown: `$X.XX` or "—" when unavailable; optional "Price unavailable" and quote_as_of when present.
- Visible on both Options and Shares tabs.

### Part 5 — Shares opened date date-picker (P2)

- **Shares form:** `<input type="date">` for opened_at; backend still accepts YYYY-MM-DD.

---

## API changes

| Area | Change |

| GET /api/ui/symbol-diagnostics | Response may include **delta_diagnostics** (request-time only): band_min, band_max, best_delta, miss, direction, best_candidate. |
