# R24.8 — Docker packaging baseline (backend + frontend)

## Scope

Add Docker and docker-compose so the app can run as backend + frontend containers. No internet exposure or auth in this release. Decision artifact semantics unchanged; no secrets in repo or images.

## Requirements

1. **Backend Dockerfile**
   - Python slim base; install deps from existing requirements.txt (or pyproject).
   - Copy backend code; expose 8000.
   - CMD: uvicorn app.api.server:app --host 0.0.0.0 --port 8000.
   - Do not copy .env into image; use env_file in compose.

2. **Frontend Dockerfile**
   - Build stage: npm ci, npm run build.
   - Serve stage: lightweight static server or nginx serving dist/.
   - Expose 3000 (or 80 in container).
   - Frontend calls backend via build-time env (e.g. VITE_API_BASE_URL for browser; document the variable).

3. **docker-compose.yml (repo root)**
   - backend: build chakraops/Dockerfile, ports 8000:8000, volumes for out/ and config if needed, env_file .env.
   - frontend: build frontend/Dockerfile, ports 3000:80 (or 5173), depends_on backend.
   - out/ bind-mounted so artifacts persist.

4. **.dockerignore**
   - Exclude out/, .venv/, node_modules/, dist/, __pycache__/, .env, etc.

5. **README**
   - Docker Quickstart: docker compose up --build, open http://localhost:3000.
   - Troubleshooting (ports, rebuild, volumes).
   - State persistence: out/ is bind-mounted.

6. **Gates and verification**
   - Run existing gates locally (pytest, frontend test, frontend build); paste tails into out/verification/R24.8/notes.md.
   - UAT: docker compose up; GET /api/ui/system-health returns 200; frontend loads dashboard.

## Non-negotiables

- Do not change decision artifact semantics (out/decision_latest.json canonical).
- Do not persist prose/UI strings in decision artifacts.
- Preserve SDLC gates; record outputs in out/verification/R24.8/notes.md.
- No secrets in repo or Docker images.
