# R26.1 — Sizing Realism: CSP Risk Proxy + Cash-Secured Reserve (Advisory-First)

## Scope

Enhance CSP sizing to respect: (1) **cash-secured reserve** — cash reserved for existing CSP obligations plus MIN_CASH_RESERVE_PCT; (2) **risk proxy sizing** — cap contracts using a conservative downside move proxy. Advisory-first; risk proxy enforcement optional via config.

## Non-negotiables

- **Decision artifacts code-only** — No prose/UI strings; no FAIL_/WARN_ in decision_latest.json.
- **UI** — Safe labels only; never raw FAIL/WARN.
- **Determinism** — Same snapshot inputs → same sizing outputs.
- **No broker automation** — Manual execution only. No new strategies.
- **Gates** — Backend pytest, frontend tests, frontend build; evidence in `out/verification/R26.1/notes.md` + UAT.

## 1) Backend: Risk proxy (CSP)

- **Module:** `app/core/portfolio/risk_proxy_r261.py`
- **Functions:**
  - `estimate_downside_move_pct(symbol_context)` → pct. Prefer implied earnings move when earnings within N days (advisory); else IV/ATR proxy; else conservative default (e.g. 7%). Deterministic; snapshot fields only.
  - `estimate_csp_max_loss_proxy(strike, contracts, downside_move_pct)` → usd. Proxy loss = (strike * downside_move_pct) * 100 * contracts; do not net premium.
  - `cap_contracts_by_risk_budget(risk_budget_usd, strike, downside_move_pct)` → contracts.

## 2) Backend: Cash-secured accounting

- Extend `sizing_r260`:
  - `cash_secured_committed_usd` = sum(open CSP contracts × strike × 100).
  - `available_cash_for_new_csp` = cash − cash_secured_committed − cash_reserve_floor.
  - If `available_cash_for_new_csp` ≤ 0 → CSP ENTRY size = 0, safe code `CONSTRAINT_CASH_SECURED`.

## 3) Wiring

- For CSP candidates: max contracts by (1) cash-secured availability (hard cap), (2) symbol cap, (3) risk proxy budget (advisory unless `CSP_RISK_PROXY_ENFORCE=true`).
- Config: `CSP_RISK_PROXY_ENFORCE` = false (default). If true, risk proxy becomes hard cap.
- Optional: `EARNINGS_DAYS_FOR_MOVE` (e.g. 14) for when to use implied earnings move.

## 4) UI

- Action Needed / Symbol Diagnostics (CSP Suggested size): show "Cash-secured available: $…", "Risk proxy move: X%", "Risk proxy loss (per contract): $…", "Risk proxy cap: N contracts" (and whether enforced). Safe labels only.
- Guardrails card: "Cash-secured committed", "CSP cash available".

## 5) Tests

- Backend: `tests/test_r261_risk_proxy_sizing.py` — cash-secured committed correct; CSP size 0 when committed + reserve > cash; risk proxy deterministic; enforcement flag; no FAIL_/WARN_ in JSON.
- Frontend: CSP suggested size shows cash-secured + risk proxy fields; no FAIL/WARN in DOM.
