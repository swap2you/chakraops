# R27.0 — Paper Trading Mode (simulated fills + P/L) for Wheel workflows

**Branch:** release/R27.0  
**Manual-only.** No broker automation. CSP/CC/SHARES only.

## Objectives

- Record simulated fills (price/premium/fees/time) from Trade Ticket.
- Maintain paper positions (open/close) with realized/unrealized P/L.
- Feed Journal/Reports with is_paper flag; no silent mixing with live.

## Non-negotiables

- Decision artifacts remain code-only; no prose/UI strings; no raw FAIL_/WARN_ in decision_latest.json.
- UI safe labels only; no FAIL/WARN words.
- Determinism: P/L and position state deterministic for same inputs.
- No broker automation; no new strategies beyond CSP/CC/SHARES.
- Gates pass; evidence in out/verification/R27.0/notes.md + UAT.

## Scope

### 1) Data model (SQLite under DATA_DIR)

- **Store:** app/core/paper/paper_store_r270.py
- **DB:** DATA_DIR/paper.db
- **Tables:** paper_positions (id, symbol, instrument_type, strategy, side, qty, contract_key, expiry, strike, right, open_ts, open_price, open_fees, status, close_ts, close_price, close_fees, realized_pl, notes); paper_fills (id, position_id, ts, action, qty, price, fees).

### 2) Backend API

- POST /api/ui/paper/execute — mode=PAPER, symbol, strategy, action (OPEN|CLOSE), qty; shares_price or option fields; creates position/fill; on success writes journal entry with is_paper=true, link_id=paper:<id>.
- GET /api/ui/paper/positions?status=&symbol=&strategy=
- GET /api/ui/paper/summary?month=YYYY-MM — realized_pl, trade_count, win_rate, fees; optional by strategy.

### 3) Journal integration

- Add is_paper (default false) to journal_entries; journal_create accepts is_paper; journal_list and journal_monthly_aggregate accept include_paper (default false for reports).
- Paper execute success → journal_create(..., is_paper=True, link_id=paper:<position_id>).

### 4) Frontend

- TradeTicketPage: "Paper execute" toggle; fill inputs (price/premium, fees); "Simulate Fill" → POST paper/execute; toast + journal-saved event.
- New /paper page: Open / Closed tabs; table symbol, strategy, qty, open price, realized.
- JournalPage / ReportsPage: "Include paper" toggle; pass include_paper to API.

### 5) Tests

- Backend: test_r270_paper_trading.py (OPEN/CLOSE shares and CSP, journal is_paper, list/summary, no FAIL_/WARN_).
- Frontend: TradeTicketPage paper UI, Paper page mocked, Journal/Reports include_paper, no FAIL/WARN in DOM.

### 6) Docs + verification

- R27.0_requirements.md, R27.0_release_notes.md, RELEASE_CHECKLIST R27.0, out/verification/R27.0/notes.md.
