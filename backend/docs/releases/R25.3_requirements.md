2. **Options position lifecycle** — Use existing tracked positions store; request-time lifecycle (profit_pct, dte, assignment_risk, recommended_action_code CLOSE/ROLL/HOLD); mark provenance/freshness; recommended_by "r253". Rules: PROFIT_TARGET_HIT (≥50% → CLOSE), ROLL_WINDOW (dte ≤ 14 and profit < 50% → ROLL), ASSIGNMENT_RISK (ITM + low DTE → CLOSE or ROLL deterministically).
3. **Options lifecycle notifications** — OPTIONS_PROFIT_TARGET_HIT, OPTIONS_ROLL_WINDOW, OPTIONS_ASSIGNMENT_RISK; trigger on transition only; dedupe (contract + event type); no spam.
4. **Frontend UX** — Symbol Diagnostics Options: lifecycle strip (Recommend, Profit %, DTE, Mark, Reason); Dashboard Action Needed: options lifecycle fields; Notifications page: render the three options lifecycle types with safe labels.
