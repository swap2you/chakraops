# R25.3 — Phase 3 Options Workflow Completion (Release Notes)

## Summary

R25.3 delivers: **EOD-biased eligibility** (config DECISION_CADENCE_MODE; eligibility uses last completed daily candle when EOD_BIASED), **options position lifecycle** (existing tracked positions + request-time CLOSE/ROLL/HOLD with recommended_by "r253"), **options lifecycle notifications** (OPTIONS_PROFIT_TARGET_HIT, OPTIONS_ROLL_WINDOW, OPTIONS_ASSIGNMENT_RISK with transition dedupe), and **frontend lifecycle strip** on Symbol Options tab + Action Needed + Notifications page with safe labels only.

## Scope

- Phase 3: EOD-biased eligibility, options lifecycle, notifications, ticket-clarity UX.
- See [R25.3_requirements.md](R25.3_requirements.md).

## Changes

### Backend

- **settings.py:** `get_decision_cadence_mode()` — returns EOD_BIASED (default) or LIVE; env DECISION_CADENCE_MODE overrides.
- **ui_routes.py:** When cadence_mode is EOD_BIASED, symbol diagnostics use last completed daily candle close for spot (eligibility); response includes `cadence_mode`, `eligibility_as_of_ts`. `_enrich_diagnostics_with_options_lifecycle(out, symbol)` adds `options_lifecycle` to symbol-diagnostics when symbol has open CSP/CC position. Action-needed options path: lifecycle with `recommended_by=RECOMMENDED_BY_R253`; calls `maybe_append_options_lifecycle_notification` on transition (profit target, roll window, assignment risk) with 24h dedupe.
- **position_lifecycle_r243.py:** Optional `recommended_by` parameter; `ASSIGNMENT_RISK_DTE_MAX = 7`; `RECOMMENDED_BY_R253`.
- **notifications_store.py:** `maybe_append_options_lifecycle_notification(symbol, contract_key, event_type, payload)` for OPTIONS_PROFIT_TARGET_HIT, OPTIONS_ROLL_WINDOW, OPTIONS_ASSIGNMENT_RISK; dedupe by contract_key+event_type within 24h.

### Frontend

- **api/types.ts:** `cadence_mode`, `eligibility_as_of_ts`, `options_lifecycle` on SymbolDiagnosticsResponseExtended.
- **SymbolDiagnosticsPage.tsx:** Options tab shows "Position lifecycle" card (Recommend, Profit %, DTE, Mark, Reason) when `data.options_lifecycle` present; data-testid="options-lifecycle-strip".
- **NotificationsPage.tsx:** Type labels and details block for OPTIONS_PROFIT_TARGET_HIT, OPTIONS_ROLL_WINDOW, OPTIONS_ASSIGNMENT_RISK (safe labels only).

### Tests

- **test_r253_options_lifecycle.py:** get_decision_cadence_mode default/override; lifecycle recommended_by r253; determinism; options notification dedupe; action-needed no FAIL_/WARN_.
