# R30.1 — Readiness: fix links + gating-aware UI (manual-only) (NO GIT)

**NO GIT.** Manual-only. No broker automation. No schedulers.

## Non-negotiables

- Manual-only. No broker automation. No schedulers/background jobs.
- Do NOT write out/decision_latest.json.
- Decision artifacts remain code-only; never persist prose/UI strings in decision artifacts.
- UI must never display raw FAIL/WARN/PASS or FAIL_/WARN_ substrings.
- Determinism: stable ordering for checks and action links.

## Goal

Make readiness actionable without enforcing trades: add per-check "Fix" links (deep link to where operator can resolve) and UI-only gating-aware behavior (highlight that status=Review is not ready; no blocking of manual actions beyond UX cues).

## Scope

### Backend: Per-check action links in readiness response

- **GET /api/ui/trade-ticket/readiness** (unchanged contract; extended check items)
  - Each check includes optional: **action_label** (safe), **action_href** (safe internal path only; no external URLs).
  - Link mapping: INTEGRITY → Open integrity, /positions?source=db&symbol=&lt;symbol&gt;; MARK_FRESHNESS → Open system diagnostics, /system; CASH_SECURED_RESERVE → Open portfolio, /portfolio; SIZING_CONSTRAINTS → Open guardrails, /system; EARNINGS_ADVISORY → Open symbol, /symbol-diagnostics?symbol=&lt;symbol&gt;; ACCOUNT_PRESENT → Open settings, /system.
  - action_href sanitized and URL-encoded for symbol where used. No forbidden tokens in action_label or href. Check order unchanged.
- Tests: **test_r301_trade_ticket_readiness_actions.py** — action links per check; hrefs internal and INTEGRITY/EARNINGS include symbol; no forbidden tokens in JSON; no decision_latest write; checks order unchanged.

### Frontend: Ready banner + Fix links

- **Execution readiness card**
  - Header/badge: "Ready to execute: OK" or "Ready to execute: Review" (safe labels).
  - If status=Review: one-line guidance "Resolve the items below before executing."
  - Per check row: check label + status; when action_label/action_href present, show "Fix" link (internal routing). "Copy order stub" unchanged.
  - No forbidden tokens in DOM.
- Tests: TradeTicketPage — Fix links present and hrefs match; "Ready to execute: Review" and guidance when status=Review; no forbidden tokens in document.textContent.
