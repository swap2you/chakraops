# R28.9 — Reconcile Diff remediation + DB-first read (operator clarity)

**NO GIT.** Manual-only. No broker automation.

## Goal

1. **Operator remediation:** When reconcile status is Review, allow a deliberate manual "Rebuild now" from the Reconcile Diff card using the existing rebuild endpoint.
2. **Operator clarity:** Provide a DB-first "what is stored" view for unified open positions (read from SQLite only), without any writes. Deterministic ordering.

## Non-goals

- No new background jobs. No broker automation. No schema changes to decision artifacts.

## Non-negotiables

- Decision JSON artifacts remain code-only and unchanged. Do not write out/decision_latest.json from these features.
- Never persist raw FAIL_/WARN_ tokens in decision artifacts.
- UI must never display raw FAIL/WARN/PASS. Safe labels only (OK/Review/Degraded/Blocked).
- Deterministic ordering for DB read and for rebuild.
- Repo hygiene: do not stage/commit out/* runtime artifacts; out/verification evidence is local-only.

## Scope

### A) Backend: DB-first read endpoint

- **GET /api/ui/positions/unified/db**
  - Query params: state=open|closed (default open), include_paper (default true), instrument_type optional, symbol optional, limit (default 500, max 2000).
  - Reads directly from unified SQLite (positions_open or positions_closed). No recompute from sources.
  - Returns: { status, status_label, count, items: UnifiedPosition[] }. Safe labels only.
  - Deterministic sort: symbol, instrument_type, expiry/strike, opened_ts, id.

- **Tests:** test_r289_positions_unified_db_read.py — deterministic order, filters (symbol, type, include_paper), no forbidden tokens in payload, no decision_latest write.

### B) Frontend: Reconcile Diff remediation + DB view

- **SystemDiagnosticsPage (Reconcile Diff card when status Review):**
  - "Rebuild now" button. Confirm: "This will rebuild the unified positions DB from authoritative sources. Manual action. Continue?" On confirm call rebuild mutation (include_paper: true). Disable while running; after success invalidate system-health + reconcile diff + unified positions; collapse details.
  - "View DB stored positions" link → /positions?source=db&include_paper=true.

- **PositionsPage:**
  - Support query param source: source=recompute (default) uses GET /api/ui/positions/unified; source=db uses GET /api/ui/positions/unified/db. Same filters. Label: "Source: Stored" or "Source: Computed".

- **Frontend tests:** Rebuild now only when Review; click triggers mutation with include_paper true; no FAIL/WARN/PASS in DOM. Positions: source=db uses db path and shows Stored; source absent shows Computed; no forbidden tokens.

- out/verification/R28.9/notes.md: gate commands, tails, UAT, grep proof.
