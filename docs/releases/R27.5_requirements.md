# R27.5 — Journal-driven backtesting baseline (replay), manual-only

**Branch:** release/R27.5  
**Manual-only.** No broker automation. No new strategies (SHARES/CSP/CC only).

## Objectives

- Deterministic backtest replay of a date range using journal entries only (audited replay of what the journal says happened).
- Modes: live-only, paper-only, or include_paper (mixed).
- Output: performance summary, trade table, exportable JSON + CSV.
- Persistence under data/ (not out/); no FAIL_/WARN_ in artifacts.

## Non-negotiables

- Decision artifacts remain code-only; no prose/UI strings; never write FAIL_/WARN_ into decision_latest.json.
- UI safe labels only; never show raw FAIL/WARN.
- Determinism: same journal inputs + same params => same backtest outputs.
- Gates pass; evidence in out/verification/R27.5/notes.md + UAT.

## Scope

1. **Backend:** backtest_runner_r275 (run_backtest from journal_list_range; SHARES/OPTIONS interpretation; metrics + per-trade rows); backtest_store_r275 (SQLite run records; files under data/reports/backtests/).
2. **API:** POST /api/ui/backtest/run; GET /api/ui/backtest/runs; GET /api/ui/backtest/download (allowlist).
3. **Frontend:** BacktestPage (date range, toggles, run, results summary + by-strategy + trades, download JSON/CSV, history); Backtest link in sidebar.
4. **Tests:** test_r275_backtest_replay.py; BacktestPage.test.tsx; sidebar includes Backtest.
5. **Docs:** R27.5_requirements.md, R27.5_release_notes.md, RELEASE_CHECKLIST, out/verification/R27.5/notes.md.
