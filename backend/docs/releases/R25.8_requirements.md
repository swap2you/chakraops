# R25.8 — Cadence Discipline + Earnings Feed Validation

## Scope

Cadence discipline: eligibility sticky within the day unless force-refresh; EOD_BIASED extended so intraday runs do not flip eligibility based on partial candles. Universe run uses last completed daily candle close for spot and daily indicators. Request-time fields: cadence_mode, eligibility_as_of_ts, eligibility_is_intraday_stale. Earnings feed validation: diagnostics-only GET /api/ui/earnings/debug; System Diagnostics earnings probe card (probe symbol default SPY). Safe labels only; no raw codes.

## Non-negotiables

- **Decision artifacts code-only** — No prose/UI strings; no FAIL_/WARN_ persisted.
- **UI** — Never display raw FAIL_/WARN_ codes; safe labels only.
- **Determinism** — Universe eval vs per-symbol recompute match under snapshot semantics.
- **SDLC** — Backend pytest, frontend tests, frontend build pass; evidence in `out/verification/R25.8/notes.md`.
- **Repo hygiene** — out/ whitelisted only; no secrets; no scratch dumps.

## 1) Cadence discipline

- Eligibility "sticky" within the day unless user explicitly force-refreshes.
- EOD_BIASED: intraday scheduler runs do NOT flip eligibility based on partial candles (universe run uses last completed daily candle close for spot and daily indicators).
- Request-time only (not persisted): **cadence_mode**, **eligibility_as_of_ts**, **eligibility_is_intraday_stale** (boolean).
- UI: small safe banner "Cadence: EOD-biased (as of \<date/time ET>)" without raw codes.

## 2) Earnings feed validation (advisory-only)

- **GET /api/ui/earnings/debug?symbol=NVDA** — diagnostics only. Returns safe fields: status (OK/Unavailable/Stale), next_date, days, implied_move_pct, as_of. Must NOT return raw ORATS payload; do not log secrets; do not persist to decision artifacts.
- System Diagnostics card: calls this endpoint for a configured probe symbol (default SPY); displays status safely.
- If fetch fails or invalid nextErn → "Unavailable" (never "Not evaluated").
