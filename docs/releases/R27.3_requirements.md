# R27.3 — Live position close workflow parity + position realism

**Branch:** release/R27.3  
**Manual-only.** No broker automation. SHARES/CSP/CC only.

## Objectives

- Live shares close from UI (parity with paper): close_price, fees, ts, notes; journal entry is_paper=false, action SELL, link_id=shares:{symbol}:{position_id}.
- Live options close/roll journaling: record CLOSE_CSP/CLOSE_CC/ROLL in Journal from Trade Ticket or "Record close" on lifecycle strip (no execution).
- Reports hygiene: live journal entries fully populate strategy/action for monthly aggregates.

## Non-negotiables

- No prose/UI strings or raw FAIL_/WARN_ in decision artifacts.
- UI safe labels only.
- Manual-only; no broker automation.
- Deterministic: realized/unrealized math fixed; mark order fixed; "—" when missing.
- Gates pass; evidence in out/verification/R27.3/notes.md + UAT.

## Scope

1. **Live shares close:** POST /api/ui/shares/positions/{symbol}/close (or extend existing) with close_price, fees, ts, notes; compute realized_pl; mark closed; auto-create journal entry is_paper=false, action SELL, link_id=shares:{symbol}:{position_id}. Frontend: Close button + modal on Shares/Portfolio; toast on success.
2. **Options close/roll journaling:** Extend so operator can record CLOSE_CSP/CLOSE_CC/ROLL in Journal (contract_key, expiry/strike/right, premium, fees, notes). No execution. From Trade Ticket or "Record close" on position lifecycle strip.
3. **Reports:** Ensure live journal entries populate strategy/action; no decision persistence changes.
4. **Tests:** test_r273_live_close_workflow.py (shares close → journal + realized_pl; options record close → journal; no FAIL_/WARN_). Frontend: close modal renders/submits (mocked); no FAIL/WARN in DOM.
5. **Docs:** R27.3_requirements.md, R27.3_release_notes.md, RELEASE_CHECKLIST R27.3 section, out/verification/R27.3/notes.md.
