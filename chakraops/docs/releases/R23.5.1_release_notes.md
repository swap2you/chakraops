## Changes

### 1. R23.4.8 verification completion

- `RELEASE_CHECKLIST.md`: R23.4.8 items (Frontend, Tests, Requirements, Release notes, Verification, Gate) marked done with evidence in `out/verification/R23.4.8/notes.md`.

### 2. Shares-tab test stabilization (R23.5.0 follow-up)

- **Root cause:** `Card` in `frontend/src/components/ui/Card.tsx` did not forward HTML attributes (e.g. `data-testid`) to the DOM, so `shares-trade-plan-card` and `shares-position-card` were never findable in tests.
- **Fix:** `Card` now extends `React.HTMLAttributes<HTMLElement>` and spreads `...rest` onto the root `<section>`, so `data-testid` and other props are applied.
- **Tests updated:** All four Shares-tab tests in `SymbolDiagnosticsPage.score.test.tsx` now use `renderWithRoute(..., "/symbol-diagnostics?symbol=...&tab=Shares")` for a stable initial URL and tab; no `it.skip` remains for these cases.
- **Close position test:** `data-testid="close-position-open-btn"` added to the “Close position” button in `SymbolDiagnosticsPage.tsx` for a stable selector; test uses `userEvent.click` and `waitFor` for the modal.

### 3. Gate results (proof)

- **Backend:** `cd chakraops && python -m pytest -v --tb=short` → 539 passed, 2 skipped.
- **Frontend tests:** `cd frontend && npm run test -- --run` → 160 passed, 18 skipped (pre-existing skips elsewhere).
- **Frontend build:** `cd frontend && npm run build` → success.

Gate outputs are recorded in `out/verification/R23.5.1/notes.md`.
