# R24.5.1 — Earnings Sanity + Scaling Fix (Patch)

**Date:** 2026-02

## What changed

- **nextErn validation:** Missing, empty, `"0000-00-00"`, or invalid date ⇒ `earnings_data_status="Unavailable"` and all earnings fields null except `earnings_as_of`.
- **earnings_days:** Use `daysToNextErn` when valid int ≥ 0; else compute calendar days from as_of (America/New_York) to nextErn when nextErn is valid.
- **impliedEarningsMove scaling:** 0 < v ≤ 1 ⇒ fraction (pct = v×100); 1 < v ≤ 50 ⇒ already percent; else null (eliminates 500%+ bogus values).
- **Status OK:** Only when nextErn valid and earnings_days computed/valid.
- **Frontend:** Hero pill only when OK + earnings_days not null + valid date; never "Earnings: 00" or 0000-00-00. Risk advisory row only when status OK.
- **Tests:** nextErn=0000-00-00 ⇒ Unavailable; implied move 0.072→7.2, 7.2→7.2, 563→null; no pill when Unavailable; no 0000-00-00 in UI.
