# Release R29.5 — Integrity remediation UX

**Date:** 2026-03  
**NO GIT.** Manual-only.

**Goal:** When integrity status is Review, provide an actionable remediation workflow: copy sanitized summary for support/debugging and clear guidance. Safe labels only; deterministic.

---

## User-visible changes

- **Positions page — Integrity (when Review):** New button **"Copy remediation summary"** copies a sanitized summary to clipboard (heading, counts, up to 10 sample items in stable order). Link **"Open diagnostics"** to System Diagnostics. Both only when status is Review.
- **System Diagnostics — Integrity Check card:** When OK: "No action needed." When Review: ordered guidance bullets — View diff details (link to Positions), Run integrity check, Rebuild unified positions. All strings sanitized.

## API / backend

- No new endpoints or behavior. Existing GET integrity-check and system-health remain safe-label only.
