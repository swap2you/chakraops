# Release R28.1 — Live close/roll mirror + reconcile advisory + System Health reconcile block

**Date:** 2026-03  
**Branch:** release/R28.1  
**Goal:** Mirror live close/roll into unified DB (idempotent); single deduped advisory when reconcile is Review; minimal reconcile visibility in System Health.

---

## Backend

- **Live mirror:** When live share close, options close, or options roll is recorded via existing endpoints, mirror into unified positions DB (positions_open / positions_closed). Stable IDs (e.g. live_shares_closed_{id}, live_options_closed_{position_id}, live_options_{position_id} for new open). Idempotent; open row removed on close where applicable.
- **Reconcile advisory:** If `get_positions_unified_reconcile_health()` returns status "Review", ensure one notification of type POSITIONS_RECONCILE_REVIEW (safe message only). Deduped: do not create if an active (NEW/ACKED) notification of that type already exists. Trigger: **after live close/roll mirror** in the same request (re-evaluate reconcile and conditionally create notification); system-health endpoint remains read-only.
- **Wiring:** `ui_shares_position_close`, `ui_positions_close`, `ui_positions_roll` call mirror helpers on success; then call reconcile-advisory helper.

## Frontend

- **System Health / System Diagnostics:** New “Unified Positions Reconcile” card: status (OK / Review), counts (paper_open, paper_closed, unified_open_paper, unified_closed_paper). Safe labels only; no FAIL/WARN.

## Tests
