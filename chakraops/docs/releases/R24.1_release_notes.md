# R24.1 — Actionable Trading Workflow v1

**Scope:** Notifications + position-aware actions + dashboard polish. No new write capabilities; decision JSON remains code-only.

## Part 1 — Position-aware next_action

- **next_action_code** (ENTRY | HOLD | CLOSE | ROLL | NONE) for OPTIONS and SHARES using existing data. CLOSE when target/stop hit; ROLL when low DTE (e.g. ≤14); ENTRY when eligible and no position.
- **next_action_details** (request-time only, not persisted) in GET /api/ui/symbol-diagnostics: `action`, `rationale_lines` (safe, plain-English), `key_numbers` (spot, t1, delta_best, dte, premium_est, etc.).
- Implemented in `app.core.next_action_r241`; wired in `_build_symbol_diagnostics_from_v2_store`.

## Part 2 — Actionable Slack message upgrade

- build_actionable_message_r240 extended for per-symbol block: next action, sizing, key levels; options: contract_key, delta_best, dte, bid/ask/spread_pct. Strict sanitization (no FAIL_/WARN_/secrets). Dedupe: same action+contract+size within N minutes unless severity changed.
- Tests: test_r240_slack_actionable_messages.py (required fields, forbidden substrings).

## Part 3 — Dashboard workflow polish

- **GET /api/ui/action-needed:** Top 5 options + top 5 shares; each item: symbol, strategy, next_action_code, rationale_lines, key_number, tab, accordion (for deep-link). **recently_changed:** stub (in-memory; empty list).
- Dashboard Action Needed card continues to use decision + positions; can be wired to action-needed API for richer rows (rationale, key number, deep-link).

## Part 4 — Retention / out/ hygiene

- Decision archives: keep `decision_latest.json` + last K per-symbol runs (DECISION_ARCHIVE_MAX / DECISION_HISTORY_KEEP, default 50). `prune_decision_archives()` and `_apply_retention` in evaluation_store_v2. Documented in RELEASE_CHECKLIST.

## Tests

- **Backend:** test_r241_next_action.py — options ENTRY/CLOSE/ROLL/HOLD; shares ENTRY/HOLD/CLOSE; build_next_action_details (no raw codes).
- **Slack:** test_r240_slack_actionable_messages.py — required fields, no FAIL_/WARN_/secrets.
