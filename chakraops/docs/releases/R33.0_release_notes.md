# R33.0 Release Notes — Decision Engine, Strategy Profiles, and Risk Correctness (COMPLETE)

_Program R31–R35, milestone 3 on `release/R31-R35-program`. Advisory and manual-only._

## Summary

R33.0 delivers one canonical, profile-driven, portfolio-aware **advisory** decision engine. It establishes a single source of truth for strategy profiles and for the decision input/output contract, wires the R32 stale-data gate into every actionable path, enforces hard risk invariants in sizing, and produces a deterministic, bounded (top 5–7) recommendation set with explicit blocked / watch / stay-in-cash outcomes. Nothing creates or routes orders; there is no silent fallback provider.

## Delivered

New package `chakraops/app/core/decision_engine/`:
- `profiles.py` + `config/strategy_profiles.yaml` — canonical Conservative/Balanced/Aggressive/Custom profiles with validation (M-8).
- `contract.py` — canonical decision input/output contract (manual-only label).
- `gates.py` — regime / earnings / liquidity / holdings / cash gates; wires the R32 `stale_data_gate` (PRICE always required; OPTIONS_CHAIN required for option strategies).
- `strategies.py` — CSP / covered-call / share-buy eligibility + deterministic scoring; stay-in-cash outcome.
- `sizing.py` — portfolio-aware sizing with hard invariants (no uncovered CC; no over-reserved CSP; no impossible quantity; cash buffer preserved).
- `ranking.py` — deterministic scoring + tie-break + top 5–7; blocked/watch/cash separation; overflow preserved in watch (not dropped silently).
- `engine.py` — orchestration to the canonical output.

API + frontend (read-only/advisory):
- `app/api/decision_engine_routes.py` — `GET /api/ui/decision-engine/profiles`, `POST /api/ui/decision-engine/evaluate` (deterministic; computes only from supplied JSON; no network).
- `frontend/src/api/types.ts` + `queries.ts` — `useDecisionProfiles`, `useEvaluateDecisions`.

## Scoring (deterministic, documented)

Option score (0–100) = 0.40*return + 0.25*delta + 0.15*dte + 0.20*liquidity. Golden vectors:
- Perfect Balanced CSP → 100.0; edge Balanced CSP → 38.5; covered-call return uses underlying price; share-buy (iv_rank 30, BULL) → 82.0.

## Mandatory invariants (enforced + tested)

- No uncovered covered call (contracts*100 ≤ shares held).
- No CSP reserving more than available cash after the buffer.
- No negative/impossible quantity.
- No action on stale/missing critical inputs.
- No hidden leverage; no automatic order creation/routing.
