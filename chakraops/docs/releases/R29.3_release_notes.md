# Release R29.3 — Integrity Check + Advisory v1

**Date:** 2026-03  
**NO GIT.** Manual-only.

**Goal:** Manual integrity check combining stored staleness and reconcile diff; safe-label result (OK/Review); optional single advisory notification when Review with dedupe. No decision artifact writes.

---

## User-visible changes

- **Positions page — Integrity strip:**
  - New button **"Run integrity check"** with confirm modal: "This will run an integrity check comparing stored positions with authoritative sources and staleness. Manual action. Continue?"
  - After run: last check status/label (OK or Review) shown inline; button shows "Check running" while request in progress.

## API

- **POST /api/ui/positions/unified/integrity-check**  
  Body: `{ "include_paper": true }`.  
  Response: `ok`, `status` (OK | Review), `status_label`, `include_paper`, `stale`, `reconcile` (status, status_label, missing_count, extra_count, mismatched_count), `checked_at_utc`. Single-process lock; if already running returns `ok: false`, status Review, status_label "Check already running". No FAIL/WARN/PASS in any field.

- **System health:** New read-only block `positions_unified_integrity_check` (last_checked_at_utc, last_status, last_status_label, last_stale, last_reconcile_*). Optional state file under out/ (safe fields only).

## Advisory

- When overall status is Review: at most one notification of type **POSITIONS_INTEGRITY_REVIEW** (dedupe: no new create if any active NEW/ACKED of that type). Safe title/message only.
