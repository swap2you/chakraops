# Release R27.2 — Paper portfolio realism + close workflow parity

**Date:** 2026-02  
**Branch:** release/R27.2  
**Goal:** Paper positions include_marks + single-position endpoint; POST /paper/close with journal CLOSE_*; PaperPage close modal, filters, refresh; Journal paper-only filter + Paper badge; Reports split Live/Paper totals.

---

## Scope

- **Paper positions:** include_marks query param (default true); GET /paper/positions/{id}; PaperPage Open: Entry, Mark, Unrealized, As-of; Closed: realized + timestamps; Refresh marks; symbol/strategy filter.
- **Close workflow:** POST /api/ui/paper/close (position_id, close_price or close_premium, close_fees, ts); journal action SELL/CLOSE_CSP/CLOSE_CC; PaperPage Close button + modal.
- **Journal:** Paper only quick filter; "Paper" badge on is_paper entries.
- **Reports:** When include_paper, split Live totals and Paper totals.
- **Tests:** test_r272_paper_close_workflow.py; frontend close modal, paper-only filter.
- **Docs:** R27.2_requirements.md, RELEASE_CHECKLIST, out/verification/R27.2/notes.md.
