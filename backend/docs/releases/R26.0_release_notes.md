# R26.0 — Portfolio-Aware Position Sizing (Wheel: CSP/CC + Shares)

**Date:** 2026-02

## Summary

Portfolio-aware position sizing: ENTRY candidates are sized to comply with guardrails (cash reserve, symbol cap, position caps). If max allowable size is 0, ENTRY is suppressed with safe reason codes. Request-time fields: recommended_qty / recommended_contracts, recommended_notional_usd, sizing_constraints_hit, sizing_recommended_by. Dashboard and Symbol Diagnostics show size, notional, and constraints. Guardrails card shows available budget. Manual execution only; no FAIL/WARN in UI or artifacts.
