# R29.7 — Integrity Export Pack v1 (manual download, sanitized, deterministic)

**NO GIT.** Manual-only. No broker automation, no schedulers.

## Non-negotiables

- Manual-only. No broker automation. No schedulers.
- Do NOT write out/decision_latest.json.
- Decision artifacts remain code-only; never persist prose/UI strings in decision artifacts.
- UI must never display raw FAIL/WARN/PASS or FAIL_/WARN_ substrings.
- Export bundle must contain no forbidden tokens and no secrets.
- Deterministic ordering for all exported lists and JSON.

## Goal

Add a manual "Download integrity bundle" action when integrity status is Review. Bundle helps debugging integrity drift without manual copy/paste.

## Scope

### Backend

- **GET /api/ui/positions/unified/integrity-bundle**
  - Query params: include_paper (default true), symbol (optional), limit (default 200, max 1000).
  - Response: Content-Type application/zip; filename integrity_bundle_<utc_ts>.zip.
  - Zip contents (all JSON, sanitized, deterministic):
    - manifest.json: generated_at_utc, include_paper, symbol, limit, counts per file.
    - integrity_check.json: get_positions_unified_integrity_check_result().
    - reconcile_diff.json: get_reconcile_diff(include_paper, symbol, limit).
    - positions_db.json: read_positions_unified_from_db(state=open, include_paper, symbol, limit).
    - positions_computed.json: build_unified_positions equivalent with same filters/limit.
    - system_health_subset.json: only positions_unified_rebuild, positions_unified_reconcile, positions_unified_integrity_check; safe labels only.
  - Sanitization: remove/rewrite whole-word FAIL/WARN/PASS; remove FAIL_/WARN_ substrings; no secrets (no env, API keys, headers).
- Tests: test_r297_integrity_bundle.py — zip contains expected files; no forbidden tokens in any JSON; deterministic for fixed fixture; no decision_latest write.

### Frontend

- PositionsPage and SystemDiagnosticsPage: when integrity status is Review, show button "Download integrity bundle". Click triggers file download from endpoint with current include_paper + symbol filter (if any). No forbidden tokens in UI.
- Tests: Button appears only when Review; clicking uses correct URL/params; document has no forbidden tokens.

### Docs + verification

- R29.7_requirements.md, R29.7_release_notes.md; RELEASE_CHECKLIST R29.7 section (unchecked until evidence).
- out/verification/R29.7/notes.md: gates + tails, UAT checklist [x] (download bundle, inspect files), grep proof (decision_latest; optional scan of exported JSON or rely on test).
