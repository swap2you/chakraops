R25.2 completes Phase 2 shares workflow: **targets/stops lifecycle** (persist and evaluate), **close recommendation** (clear UX when target/stop hit), and **in-app notification trigger** (SHARES_EXIT_SIGNAL with dedupe). ## Changes

### Backend

- **holdings_db.py:** `share_positions` table: added `target_price`, `stop_price` (REAL NULL). Migration for existing DBs. `upsert_share_position` accepts and returns `target_price`, `stop_price`; soft validation (stop &lt; entry, target &gt; entry when avg_cost present). `_row_to_share_position` and all SELECTs include new columns.
- **next_action_r241.py:** `compute_shares_exit_signal(last_price, target_price, stop_price)` → (hit_type: TARGET|STOP|None, reason_safe). Safe labels only ("Target hit", "Stop hit").
- **ui_routes.py:** Symbol diagnostics: when shares position has target/stop and spot available, compute shares_exit_* (request-time only); if hit, set next_action_code CLOSE and add shares_exit_hit_type, shares_exit_reason_safe, shares_exit_last_price, shares_exit_target_price, shares_exit_stop_price, shares_exit_as_of_ts. Action-needed SHARES items include shares_exit_* when present. POST /api/ui/shares/positions/{symbol} body accepts target_price, stop_price.
- **notifications_store.py:** `maybe_append_shares_exit_notification(symbol, hit_type, last_price, target_price, stop_price, as_of_ts)` — appends type SHARES_EXIT_SIGNAL with safe message; dedupe: no duplicate for same symbol+hit_type within 24h (NEW/ACKED). Called from diagnostics build when hit detected.

### Frontend

- **api/types.ts:** `SharePosition` has optional `target_price`, `stop_price`. `SymbolDiagnosticsResponseExtended` has shares_exit_* (request-time only).
- **api/queries.ts:** `useUpsertSharePosition` payload includes optional `target_price`, `stop_price`.
- **SymbolDiagnosticsPage.tsx:** Shares tab: Position card shows Target/Stop when set. Add/Update modal: target_price, stop_price inputs. When `shares_exit_hit_type` is TARGET or STOP, banner "Recommend: Close" + "Reason: Target hit" (or Stop hit) with last price and target/stop (data-testid="shares-exit-recommend-banner").
- **NotificationsPage.tsx:** When type is SHARES_EXIT_SIGNAL, display "Shares exit" and details block (Target hit/Stop hit, last/target/stop prices).

### Tests

- **test_r252_shares_exit_lifecycle.py:** compute_shares_exit_signal (target hit, stop hit, no hit, no last_price); shares_exit_* not in persisted artifact; symbol-diagnostics and action-needed no FAIL_/WARN_; maybe_append_shares_exit_notification dedupe.
- **test_share_positions_r230.py:** upsert with target_price, stop_price and assert returned/read.

## Key behavior

- **Request-time only:** shares_exit_* and next_action CLOSE from position target/stop are computed at request time; never written to decision_latest.json or any persisted artifact.
- **Dedupe:** One SHARES_EXIT_SIGNAL per (symbol, hit_type) within 24h; second call with same symbol+hit_type returns without appending. Re-notify only after ARCHIVED or after window.
- **Safe labels:** All user-facing text uses "Target hit", "Stop hit", "Recommend: Close"; no FAIL_/WARN_ in API or UI.

## How to test manually

1. Add/update a shares position with target_price and stop_price (Symbol page → Shares tab → Position → Update, or POST /api/ui/shares/positions/{symbol} with body `{ "account_id": "default", "quantity": 100, "avg_cost": 140, "target_price": 150, "stop_price": 130 }`).
2. Load symbol-diagnostics for that symbol with a spot price that crosses target (e.g. ≥ target_price) or stop (≤ stop_price); confirm "Recommend: Close" banner and next_action_code CLOSE.
3. Notifications: trigger a hit (e.g. mock or real price), open Notifications page; confirm one SHARES_EXIT_SIGNAL with "Shares exit" and safe details. Reload diagnostics again; confirm no duplicate notification.
4. Action Needed: with a shares position in CLOSE (target/stop hit), confirm Dashboard Action Needed shows the shares row with CLOSE and reason.
5. Grep: `rg -n "FAIL_|WARN_" out/decision_latest.json` (or equivalent) must show no matches for these substrings in persisted artifact.
