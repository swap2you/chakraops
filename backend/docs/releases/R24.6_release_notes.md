# R24.6 — UI Audit + Safe Labels + Account Reset Clarity

**Date:** 2026-02

## What changed

- **Safe labels:** Gate/status badges and tables no longer show raw "FAIL" or "WARN". Mapping: PASS → "Passed", FAIL → "Blocked", WARN → "Degraded". Single helper used across Gate Summary, Risk Flags, Analysis gates table, Portfolio risk card, System Status, TickerIntelligencePanel, WheelPage, RankedTable, TopOpportunities.
- **StatusBadge:** Displays safe label only (never "FAIL"/"WARN").
- **Account reset note:** Portfolio page shows a short "Data reset likely" message when positions are empty, with guidance to re-add via Trade Ticket or import; pointer to docs (no raw paths in artifacts).
- **Earnings:** Details drawer (debug) can show earnings status + as_of; hero pill and Risk Flags remain guarded per R24.5.1.
- **Tests:** FE regression ensures no word-boundary FAIL/WARN in document text; backend no FAIL_/WARN_ tests unchanged.
