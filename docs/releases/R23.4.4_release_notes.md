# Release R23.4.4 — Symbol Diagnostics Options Fix Pack

**Date:** 2026-02  
**Goal:** Fix Execution Console Options tab missing data and clutter when loading symbol diagnostics from store (diagnostics not persisted).

---

## Changes

### Backend

- **Request-time technicals:** When diagnostics_details is missing, `_build_technicals_at_request_time(symbol, spot)` runs the eligibility engine (same as evaluation) and returns rsi, atr, atr_pct, support_level, resistance_level, regime, spot. Only non-null values are returned.
- **Request-time exit plan:** When technicals are rebuilt and exit_plan has no t1/t2/stop, `build_exit_plan` is called with minimal eligibility trace so targets and stop are populated when inputs allow.
- **Explanation:** When explanation is missing, minimal explanation is built from regime and technicals (stock_regime_reason, support_condition, resistance_condition) so candidate table regime/support columns show values.
- **Rejected count:** When sample_rejected_due_to_delta is empty but summary has rejected_due_to_delta_count, computed_values.rejected_count is set from summary.
- **Stock fallback:** (Existing) When stock is missing, price/underlying_price/quote_as_of derived from summary.

### Frontend

- **Details accordion:** As-of/Inputs and "Debug: raw reason" moved into a collapsible &lt;details&gt; "Details" section.
- **Score breakdown:** When score_caps.applied_caps exist, a "Capped by" line shows reason and before → after; applied caps list retained below.
- **Options tab:** Shares plan remains only on Shares tab (unchanged). Technical details, Targets & hold-time, Exit plan render from API; no change to candidate columns (populated from symbol-level explanation when backend sends it).

### Files

- `chakraops/app/api/ui_routes.py` — _build_technicals_at_request_time; _build_symbol_diagnostics_from_v2_store (rebuild technicals/exit_plan/explanation/rejected_count when diag missing).
- `frontend/src/pages/SymbolDiagnosticsPage.tsx` — Collapsible Details; Score breakdown "Capped by".
- `docs/releases/R23.4.4_requirements.md`, `R23.4.4_release_notes.md`; `out/verification/R23.4.4/notes.md`; `chakraops/docs/releases/RELEASE_CHECKLIST.md`.
