# R28.5 — Live options OPEN mirror wiring

**Branch:** release/R28.5 (operator creates)  
**Manual-only.** No broker automation.

## Goal

Eliminate remaining open-position drift by wiring the live OPTIONS OPEN mirror into unified wherever a live options position is created/updated via UI routes. Reconcile health already includes live options open counts (R28.4); ensure mirror is called on write and advisory notification pattern is preserved.

## Non-negotiables

- Decision artifacts code-only; no FAIL_/WARN_ or prose/UI strings.
- UI must never render raw FAIL/WARN/PASS; safe labels only.
- No broker automation. Deterministic ordering and stable IDs.
- Notification creation only on write flows (not on system-health fetch).

## Scope

### Backend

- **Live options open mirror** — `mirror_live_open_to_unified(pos)` in `positions_unified_store_r279.py` (existing). Stable id `live_options_{position_id}`; idempotent.
- **API wiring** — After successful live options create/update (e.g. POST /positions/manual-execute when account != paper and strategy CSP/CC), call `mirror_live_open_to_unified(position.to_dict())` and `ensure_reconcile_advisory_notification()`.
- **Reconcile health** — `get_positions_unified_reconcile_health()` includes `live_options_open_count`, `unified_open_live_options_count`; status OK or Review only.

### Tests

- **test_r285_positions_unified_live_options_open_wiring.py** — live options upsert wires mirror idempotent; reconcile health has live options counts and safe labels only; wiring does not write decision_latest.

### Frontend

- Only if needed: typings for `positions_unified_reconcile` already include live options keys (R28.4). No DOM raw tokens.

## UAT

- [ ] Create a live options position via UI (or manual-execute route) → appears on /positions as LIVE, Type CSP/CC; no duplicate on repeat.
- [ ] Reconcile mismatch → status Review (not FAIL/WARN); at most one deduped advisory notification.
- [ ] No raw FAIL/WARN/PASS in System Diagnostics or Positions DOM.
