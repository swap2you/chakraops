# Release R23.5.0 — Shares page overhaul (Trade Plan + lifecycle)

**Date:** 2026-02  
**Goal:** Shares tab as structured Trade Plan view with accordions; Close position with closed history and realized/unrealized P/L.

---

## Scope

- **In scope:** Symbol Diagnostics → Shares tab: accordions (Trade Plan, Technicals, Risk & Details, Position). Trade Plan: Spot, Entry zone, Stop, Targets, Invalidation, Hold-time + plain-English + Why eligible/Why not checklist. Close position: exit_price, exit_date, notes; closed history; realized P/L (closed), unrealized P/L (active). Consistency with symbol-diagnostics API; no Shares on Options tab. Tests and docs.
- **Out of scope:** Strategy/evaluation logic changes. Copilot behavior changes.

---

## Backend (minimal)

- **R23.5.0:** Table `share_positions_closed`; `close_share_position(account_id, symbol, exit_price, exit_date?, notes?)`; `list_closed_share_positions(account_id)`.
- **Endpoints:** `POST /api/ui/shares/positions/{symbol}/close` (body: account_id?, exit_price, exit_date?, notes?); `GET /api/ui/shares/positions/closed?account_id=`.

---

## Frontend

- **Shares tab:** Four accordions: Trade Plan (default open), Technicals, Risk & Details, Position. Trade Plan card: Spot, Entry zone, Stop, T1/T2/T3, Invalidation, Hold-time (formula + plain-English + info drawer), Why eligible/Why not checklist, sizing when present.
- **Position accordion:** Your Shares Position (quantity, avg cost, unrealized P/L when last_price available); Update, **Close position**, Delete. **Close position** opens modal: Exit price (required), Exit date (default today), Notes (optional). On success: position removed from active; closed list shows realized P/L. Closed positions (this symbol) listed when any.
- **Consistency:** Shares tab uses same `data.shares_plan` / `data.shares_position` as API; Options tab does not render Shares content.
