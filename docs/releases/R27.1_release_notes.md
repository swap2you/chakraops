# Release R27.1 — Paper-to-live parity + analysis hygiene

**Date:** 2026-02  
**Branch:** release/R27.1  
**Goal:** Paper positions show mark/unrealized when quotes available; reporting hygiene (included_paper, mode, live/paper close packs); sizing context stored as journal tags.

---

## Scope

- **A) Paper mark + unrealized:** Positions API returns request-time mark_value, mark_source, mark_age_sec, quote_ts, unrealized_pl_usd for OPEN positions; SHARES from last_price, OPTIONS from contract quote (MID→LAST→BID→ASK). Frontend: Mark and Unrealized P/L columns on Paper page.
- **B) Reporting hygiene:** GET reports/monthly response includes included_paper and mode (LIVE_ONLY|PAPER_ONLY|MIXED). POST reports/monthly/close?include_paper=true|false writes to data/reports/YYYY-MM/live/ or .../paper/; monthly_report.json includes included_paper and mode. GET files/download accept pack=live|paper.
- **C) Sizing context:** Paper execute accepts optional sizing_constraints_hit, budget fields; stored as journal tags (constraint:...). TradeTicketPage sends sizing_constraints_hit.
- **Tests:** test_r271_paper_parity.py; frontend PaperPage, ReportsPage, Monthly close.
- **Docs:** R27.1_requirements.md, RELEASE_CHECKLIST, out/verification/R27.1/notes.md.
