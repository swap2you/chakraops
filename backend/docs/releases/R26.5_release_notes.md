# R26.5 — Monthly close + performance pack (journal-driven)

## Summary

Journal-driven monthly close pack: generate a deterministic set of files (JSON, CSV, journal export, summary) under `data/reports/<YYYY-MM>/`, with UI on Reports page to generate and download. State stored in SQLite for last-run display.

## Changes

- **Backend**
  - New store: `app/core/ops/monthly_close_store_r265.py` — base path for `data/reports/`, table `monthly_close_state` (month, generated_ts, paths_json), init/get/set; path override for tests.
  - Close pack generator: builds `monthly_report.json` (totals, by_strategy, winners/losers, optional guardrails snapshot safe numeric only), `monthly_report.csv`, `journal_export.csv`, `summary.txt` (6–10 lines, no FAIL/WARN). Deterministic ordering (e.g. by created_ts).
  - **POST /api/ui/reports/monthly/close?month=YYYY-MM** — generates pack, writes state.
  - **GET /api/ui/reports/monthly/close/files?month=YYYY-MM** — returns file list + sizes.
  - **GET /api/ui/reports/monthly/close/download?month=YYYY-MM&file=...** — streams file; allowlist: monthly_report.json, monthly_report.csv, journal_export.csv, summary.txt.
- **Frontend**
  - Reports page: "Monthly Close" panel — Generate close pack button, last generated_ts and relative paths, download links for JSON/CSV/TXT.
- **Tests**
  - `tests/test_r265_monthly_close_pack.py`: pack in temp dir, deterministic contents, allowlist, no FAIL_/WARN_ in API JSON.
  - Reports page: Monthly Close panel rendered, Generate mutation, no FAIL/WARN in DOM.

## Behavior

- Generate overwrites existing month folder; same journal data produces same file contents and ordering.
- Guardrails snapshot in JSON is optional; only safe numeric/status fields (no raw codes).
- Download endpoint validates `file` against allowlist to avoid path traversal.

## How to test

1. Run backend tests: `pytest tests/test_r265_monthly_close_pack.py -v`
2. Run frontend tests: `npm run test -- --run ReportsPage`
3. Manual: Reports → Monthly Close → pick month → Generate close pack → verify files under `data/reports/<month>/` → use download links.
