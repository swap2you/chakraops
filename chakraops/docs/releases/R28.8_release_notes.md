# Release R28.8 — Reconcile Diff v1 (read-only, operator explainability)

**Date:** 2026-02  
**NO GIT.** Manual-only.

**Goal:** Operator can see what is mismatched when reconcile status is Review (missing/extra/mismatched) without touching SQLite. Read-only; no writes; safe labels only.

---

## What changed

### Backend

- **positions_unified_store_r279.py**
  - `_read_positions_open_from_db(symbol?)` — read positions_open from unified DB into list of dicts (deterministic order).
  - `get_reconcile_diff(include_paper=True, symbol=None, limit=200)` — compare build_unified_positions("open") vs DB; return missing_count, extra_count, mismatched_count, items (kind, id, symbol, instrument_type, is_paper, fields_diff). Deterministic sort; limit applied; safe labels only.
- **ui_routes.py**
  - GET /api/ui/positions/unified/reconcile-diff (include_paper, symbol, limit). Returns get_reconcile_diff() result.

### Frontend

- **api/types.ts** — UiReconcileDiffItem, UiReconcileDiffResponse.
- **api/queries.ts** — uiPositionsUnifiedReconcileDiffPath, queryKeys.uiReconcileDiff, useReconcileDiff(include_paper, symbol, limit, enabled).
- **SystemDiagnosticsPage.tsx** — "Unified Positions Reconcile Diff" card: counts when status is Review, "View details" toggle, list with link to /positions?symbol=X. useReconcileDiff enabled when reconcile status === "Review".
- **SystemDiagnosticsPage.test.tsx** — R28.8 diff card renders; View details toggles when status Review; no FAIL/WARN/PASS in document.

### Tests

- **test_r288_reconcile_diff.py**: deterministic ordering; filters; no forbidden tokens; no decision_latest write; limit applied.
