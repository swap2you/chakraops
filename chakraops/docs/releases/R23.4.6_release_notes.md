# Release R23.4.6 — Symbol Diagnostics UX + Explainability Pack

**Date:** 2026-02  
**Goal:** Premium Execution Console via Hero header, 3 accordions in Options tab, Copilot as slide-over drawer (default closed), explainability tooltips, and reduced "—" spam.

---

## Scope

- **In scope:** Hero header (symbol, price, quote_as_of, verdict, score, band, regime, primary reasons, Recompute, Copilot button). Options tab: Trade / Technicals / Risk & Details accordions. Copilot drawer (button opens, X and ESC close). Tooltips for RSI, ATR, ATR%, Regime, Support, Resistance, Delta band, bar_count, Hold-time, Targets basis, Invalidation. Targets card copy and targets_already_exceeded guidance. Details (as-of, debug) in Risk accordion. Optional "Not available" for missing data.
- **Out of scope:** Backend changes (none unless single request-time explanation string needed). No decision persistence changes.

---

## UI changes

- **Execution Console:** Hero header replaces previous symbol card; single full-width column; no permanent Copilot column.
- **Options tab:** Trade (default open), Technicals, Risk & Details accordions. Gate Summary, Delta, Candidates, Exit Plan, Targets in Trade. Technical details + MTF in Technicals. Risk flags, Score breakdown, Details (collapsible), info drawer in Risk & Details.
- **Copilot:** Button in hero; drawer overlay from right; close via X or ESC.
- **Tooltips:** Expanded INFO_DRAWER_CONTENT and inline tooltips for listed fields.
- **Targets & hold-time:** Description text and "Targets already exceeded at snapshot; recompute for updated levels." when flagged.
