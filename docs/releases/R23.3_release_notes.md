# Release R23.3 — Shares Recommendation Spine (Eligibility + Plan + Sizing + Universe Badge)

**Date:** 2026-02  
**Goal:** Turn Shares into a premium operator workflow: clear eligibility (code-only reasons), actionable plan (entry zone, stop, targets, hold-time), sizing (risk budget / stop distance), and Universe-level shares indicator and filters.

---

## Scope

### Part A — Shares eligibility (request-time only)

- **Rules:** SHARES_ELIGIBLE when: stock quality (Stage 1) pass, regime UP (or NEUTRAL if SHARES_ALLOW_REGIME_NEUTRAL), near support (distance ≤ SHARES_NEAR_SUPPORT_PCT), RSI in range (or bypass if missing), data OK.
- **reason_codes:** Code-only (e.g. SHARES_ELIGIBLE, NOT_STOCK_QUALITY, NOT_NEAR_SUPPORT, REGIME_NOT_PREFERRED, RSI_OUT_OF_RANGE, DATA_STALE). UI maps to safe text.
- **shares_plan** in GET /api/ui/symbol-diagnostics: eligible, reason_codes, spot, entry_zone (low, high, basis), stop (price, basis), targets (t1, t2, basis), hold_time (sessions_to_t1, method), sizing, as_of_inputs. **Not persisted.**

### Part B — Sizing

- Risk budget = account value × SHARES_RISK_PCT_DEFAULT (0.5%); suggested_shares = floor(risk_budget / stop_dist); cap by available_cash.
- sizing.basis = ACCOUNT_RISK or INSUFFICIENT_DATA.

### Part C — UI Shares tab (Plan view)

- Eligibility badge; Why list (safe labels from reason_codes); Plan card (spot, entry zone, stop, targets, hold-time, sizing); tooltips; Your Shares Position unchanged.

### Part D — Universe

- "Shares" column: ELIGIBLE / NOT_ELIGIBLE / N/A.
- "Shares eligible" filter chip; "Sort by Shares eligibility" option.

### Config (trade_rules.py)

- SHARES_NEAR_SUPPORT_PCT = 0.02  
- SHARES_RISK_PCT_DEFAULT = 0.005  
- SHARES_ALLOW_REGIME_NEUTRAL = False  
- SHARES_ENTRY_ZONE_ATR_MULT = 0.25  
- SHARES_STOP_ATR_MULT = 1.0  
- **SHARES_UAT_FORCE_ELIGIBLE_SYMBOLS** (UAT-only): Comma-separated symbols; when set, those symbols are treated as shares-eligible at request time with reason_codes including SHARES_UAT_FORCED. No production logic change when unset; override does not persist into decision artifacts.

---

## API changes

- **GET /api/ui/symbol-diagnostics:** Response includes `shares_plan` (R23.3 shape: eligible, reason_codes, entry_zone with basis, stop with basis, targets with basis, hold_time with method, sizing, as_of_inputs). Request-time only.
- **GET /api/ui/universe:** Each symbol in `symbols` includes optional `shares_eligible` (boolean). Request-time only.
