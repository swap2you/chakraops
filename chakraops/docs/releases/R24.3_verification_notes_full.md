## R24.3.1 (validation/health patch)

- **Portfolio risk notifier**: Component writing `out/portfolio_risk_notify_state.json` is `chakraops/app/core/portfolio/risk_notify_state.py` (throttle state when emitting PORTFOLIO_RISK notifications). `last_status=FAIL` occurred when `evaluate_portfolio_risk` returned FAIL (limit breach) or when the diagnostics check raised (e.g. account/positions unavailable). Fix: (1) Exception path now returns status **SKIP** with safe `details.reason` ("Check skipped: account or data unavailable"); (2) State file now includes `last_status_label` (Limit breach / Advisory / OK); (3) System Health exposes `portfolio_risk_notifier` with safe status/label only (OK, Degraded, Advisory). UI shows safe labels only; no raw FAIL/WARN in payloads.
- **UAT**: All items above checked; lifecycle rendering path verified via DIAG_TEST and unit tests in absence of tracked positions.
- **Commands**: Run diagnostics including portfolio_risk: `POST /api/ui/diagnostics/run?checks=portfolio_risk`. System health: `GET /api/ui/system-health` (includes `portfolio_risk_notifier.status` / `portfolio_risk_notifier.label`).
