# R28.6 — Live open mirror wiring completeness + regression guardrails

**Branch:** release/R28.6 (operator creates)  
**Manual-only.** No broker automation.

## Goal

Make live OPEN mirroring “wiring complete” across ALL live position create/upsert entrypoints (shares + options). Add guardrail tests so any future endpoint that creates a live position cannot silently bypass unified mirroring. Keep safe-label discipline and determinism.

## Non-goals

- No new UI pages. No broker automation. No schema-breaking changes.
- No changes to decision artifacts.

## Non-negotiables

- Decision artifacts remain code-only; never write out/decision_latest.json from mirror/reconcile paths; never persist FAIL_/WARN_ or prose/UI strings.
- UI must never render raw FAIL/WARN/PASS; safe labels only (OK/Review/Degraded/Blocked etc.).
- Determinism: stable IDs (live_shares_{id}, live_options_{position_id}), idempotent upserts, no unordered iteration changes.
- Mirror and reconcile advisory only on write flows; never on system-health or list fetches.

## Scope

### Backend — audit + wire missing live OPEN paths

- **Audit:** Locate every API route that can create or materially “open” a live position (shares + options).
- **Shares:** Beyond ui_shares_position_upsert (R28.4) — confirm no other share open path; wire if any.
- **Options:** Beyond POST /api/ui/positions/manual-execute (R28.5) and roll (R28.1) — wire POST /api/positions/manual-execute (server route) so it also calls mirror_live_open_to_unified + ensure_reconcile_advisory_notification when account != paper and strategy CSP/CC.
- **Per path:** After successful live write, call correct mirror (mirror_live_shares_open_to_unified or mirror_live_open_to_unified) then ensure_reconcile_advisory_notification(). No mirroring on read-only fetches.

### Tests — wiring completeness regression

- **test_r286_live_open_mirror_wiring_completeness.py:**
  - For each live-open endpoint: test that endpoint performs write, unified DB receives expected OPEN row, idempotent (call twice → still one row).
  - Safety test: wiring paths do NOT write out/decision_latest.json.
  - Safe-label test: reconcile health and unified position payloads contain no FAIL/WARN/PASS tokens.

### Docs + verification

- R28.6 requirements, release notes, RELEASE_CHECKLIST section.
- out/verification/R28.6/notes.md: gate commands + pasted tails, UAT [x], grep proof.
