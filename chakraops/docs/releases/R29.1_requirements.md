# R29.1 — Positions Trust Banner v1 (Integrity strip)

**NO GIT.** Manual-only. No broker automation.

## Goal

Bring reconcile status + diff summary onto /positions so the operator can decide quickly:
- When Source = Stored: show "Integrity" strip with reconcile status (OK/Review), diff counts when Review, actions: View diff details (inline expand), Rebuild unified positions, Switch to Computed.
- When Source = Computed: minimal note "Integrity: Computed (authoritative)" and Switch to Stored link.
- No FAIL/WARN/PASS strings in the DOM.

## Non-goals

- No new backend endpoints. No notification creation. No background jobs.

## Non-negotiables

- Decision artifacts code-only; do not write out/decision_latest.json.
- Never persist FAIL_/WARN_ in decision artifacts. UI and API safe labels only.
- No FAIL/WARN/PASS in DOM or persisted state. Deterministic ordering unchanged.
