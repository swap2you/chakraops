# R26.1 Release Notes — Sizing Realism: CSP Risk Proxy + Cash-Secured Reserve

## Summary

- **Cash-secured reserve:** CSP sizing uses cash available after reserving for existing CSP obligations (strike × 100 × contracts) and MIN_CASH_RESERVE_PCT. When insufficient, CSP ENTRY size = 0 with safe code.
- **Risk proxy (advisory-first):** Downside move % from earnings implied move (when within N days), else ATR/IV proxy, else default 7%. Risk proxy caps contracts; enforcement is optional via `CSP_RISK_PROXY_ENFORCE`.
- **UI:** Action Needed and Symbol Diagnostics show cash-secured available, risk proxy move %, risk proxy loss per contract, risk proxy cap (and enforced flag). Guardrails card shows cash-secured committed and CSP cash available.

## Backend

- **risk_proxy_r261.py:** `estimate_downside_move_pct`, `estimate_csp_max_loss_proxy`, `cap_contracts_by_risk_budget`.
- **sizing_r260:** Cash-secured committed and available cash for new CSP; `CONSTRAINT_CASH_SECURED`; CSP advisory fields (risk_proxy_*).
- **Config:** `CSP_RISK_PROXY_ENFORCE` (default false), optional `EARNINGS_DAYS_FOR_MOVE`.

## Frontend

- ActionNeededItem / Suggested size: cash_secured_available_usd, csp_risk_proxy_move_pct, csp_risk_proxy_loss_per_contract_usd, csp_risk_proxy_cap_contracts, csp_risk_proxy_enforced.
- Guardrails card: cash_secured_committed_usd, csp_cash_available_usd.
