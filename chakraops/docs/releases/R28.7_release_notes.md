# Release R28.7 — Unified Positions Rebuild v1 (manual) + Diagnostics UI action

**Date:** 2026-02  
**NO GIT.** Manual-only. No broker auto-execution.

**Goal:** Operator-controlled rebuild of unified positions DB from authoritative sources; safe labels only; no decision artifact impact.

---

## What changed

### Backend

- **positions_unified_store_r279.py**
  - `rebuild_positions_unified(include_paper=True)`: Single-process lock; wipe positions_open/positions_closed; rebuild from live shares (holdings_db), tracked live options, paper store (if include_paper). Deterministic ordering; same stable IDs (paper_*, live_shares_*, live_options_*). Returns only safe fields (status, status_label, rebuilt_open, rebuilt_closed, include_paper, started_at_utc, finished_at_utc).
  - State file out/positions_unified_rebuild_state.json: status, status_label, last_rebuild_at_utc, last_rebuild_open_count, last_rebuild_closed_count, last_include_paper. No FAIL/WARN/PASS.
  - `get_positions_unified_rebuild_health()` for system-health block.

- **ui_routes.py**
  - POST /api/ui/positions/unified/rebuild (include_paper query, default true). Returns { ok, result }. If rebuild already running: ok=false, status Review, status_label "Rebuild already running".
  - System-health block positions_unified_rebuild.

### Frontend

- **api/types.ts** — UiPositionsUnifiedRebuild; UiPositionsUnifiedRebuildResult; UiPositionsUnifiedRebuildResponse.
- **api/queries.ts** — usePositionsUnifiedRebuild() mutation; invalidates system-health and unified positions on success.
- **SystemDiagnosticsPage.tsx** — "Unified Positions Rebuild" card (status, last rebuild, counts); "Rebuild unified positions" button with confirm dialog; safe labels only. Diagnostics history overall status uses safe display label (no raw PASS in heading).
- **SystemDiagnosticsPage.test.tsx** — Rebuild card and button; click triggers mutation with include_paper true; document has no FAIL/WARN/PASS.

### Tests

- **test_r287_positions_unified_rebuild.py**: idempotent/deterministic counts; endpoint safe labels; no decision_latest write; state file no forbidden tokens.
