## How to Use Short Commands

Instead of sending a large prompt, send one line:

```
CURSOR BUILD R31.0
```

Cursor reads `docs/ai/releases/R31.0/RELEASE_PACKET.md` and `cursor_build.md`, implements only approved scope, updates `STATUS.md` and `TOOL_LOG.md`, and returns a STEP report.

All commands are defined in `docs/ai/QUICK_COMMANDS.md`.
