# R27.1 — Paper-to-live parity + analysis hygiene

**Branch:** release/R27.1  
**Manual-only.** No broker automation. SHARES/CSP/CC only.

## Objectives

- Make paper positions comparable to live by showing mark/unrealized P/L when quotes available.
- Prevent paper from silently mixing with live in reports/close packs.
- Preserve guardrails/sizing context for paper fills for later analysis.

## Non-negotiables

- Decision artifacts remain code-only; no prose/UI strings; no raw FAIL_/WARN_ in decision_latest.json.
- UI safe labels only; no FAIL/WARN words/codes.
- Determinism: identical inputs → identical outputs; marks show as_of and source; if missing show "—".
- Gates pass; evidence in out/verification/R27.1/notes.md + UAT.

## Scope

### A) Paper mark + unrealized P/L (advisory)

- **Backend:** Extend paper positions API (request-time only): mark_value, mark_source, mark_age_sec, quote_ts, unrealized_pl_usd. SHARES: last_price from diagnostics/quotes; OPTIONS: contract quote resolver, mark order MID→LAST→BID→ASK; do not persist.
- **Frontend:** PaperPage Open table: Mark (value + source + age), Unrealized P/L; Closed stays realized only.

### B) Reporting hygiene

- **Backend:** Reports monthly: include_paper defaults false; response includes included_paper: bool, mode: "LIVE_ONLY"|"PAPER_ONLY"|"MIXED". Monthly close: include_paper param; pack under data/reports/YYYY-MM/live/ or .../paper/; monthly_report.json has included_paper and mode; downloads allow subdir, no path traversal.
- **Frontend:** ReportsPage shows mode from response; Monthly close: toggle "Generate live pack" / "Generate paper pack".

### C) Sizing/guardrails context for paper fills

- **Backend:** Paper execute accepts optional sizing_constraints_hit (safe codes), available_budget_usd, cash_secured_committed_usd, csp_cash_available_usd; store as journal tags (e.g. constraint:cash_secured).
- **Frontend:** TradeTicketPage paper payload includes sizing_constraints_hit from ticket; journal display already shows tags.

### D) Tests + docs

- Backend: test_r271_paper_parity.py (mark fields, mode, close pack subdir, no FAIL_/WARN_).
- Frontend: PaperPage Mark/Unrealized; ReportsPage mode; Monthly close paper pack; no FAIL/WARN in DOM.
- R27.1_requirements.md, R27.1_release_notes.md, RELEASE_CHECKLIST, out/verification/R27.1/notes.md.

## UAT checklist

- [ ] Monthly close generates separate live/ vs paper/ packs; downloads work.
