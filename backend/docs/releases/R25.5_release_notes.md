# R25.5 — Phase 5 Journaling + Monthly Reporting Baseline (Release Notes)

## Summary

SQLite-backed trade journal for manual executions (SHARES: BUY/SELL; OPTIONS: OPEN_CSP, CLOSE_CSP, OPEN_CC, CLOSE_CC) and baseline monthly reporting. Single-user; no broker integration. Journal stored in data/journal.db. UI: Journal page (table, filters, add modal, export CSV) and Reports page (monthly summary, winners/losers).

## Changes

- **Backend:** Journal store (app/core/journal/journal_store.py), data/journal.db. APIs: GET/POST/PATCH journal, POST journal/export (CSV), GET reports/monthly. Safe responses only. Bugfix: journal_list WHERE clause (was " AND ...", corrected to " WHERE ...").
- **Frontend:** Journal page, Reports page, sidebar links. No FAIL/WARN in UI.
- **Tests:** tests/test_r255_journal.py (create/list, patch, export CSV, monthly aggregate, API response hygiene); JournalPage.test.tsx, ReportsPage.test.tsx (mocked hooks, no FAIL/WARN in document).
- **Safety:** Journal DB separate from decision artifacts; input validation; safe errors.
