## Summary

Ops hardening for deployed ChakraOps: GET /api/healthz returns lightweight {status, ts}; Docker restart policy and log rotation; backup script for out/ with retention. Same-origin /api and decision semantics unchanged.

- **README** — Backup and restore instructions.
- **Verification** — out/verification/R25.0/notes.md with gate outputs and UAT.
