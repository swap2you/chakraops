# R23.5.0 — Shares page overhaul (Trade Plan + lifecycle)

**Goal:** Symbol Diagnostics → Shares tab becomes a structured Trade Plan view with accordions; add Close position action with closed history and realized/unrealized P/L. Consistency with API; no Shares content on Options tab.

---

## Acceptance criteria

### 1) Shares tab — Trade Plan view
- **Sections (accordion style, matching Options):** Trade Plan, Technicals (reuse), Risk & Details (reuse), Position.
- **Trade Plan section shows:** Spot, Entry zone (low–high), Stop, Targets (T1/T2/T3), Invalidation, Hold-time estimate.
- Plain-English explanations for hold-time and targets basis using existing info drawer pattern.
- **Why eligible / Why not:** Checklist of shares rules (not prose). Use reason_codes/eligibility_codes/why; format as labeled checks.

### 2) Shares Position lifecycle
- **Close position** action for shares positions.
- Closing requires: **exit_price**, **exit_date** (default now), optional **notes**.
- After close: move record to closed positions history; remove from active list; compute **realized P/L**.
- UI: **realized P/L** for closed; **unrealized P/L** for active when last_price is available.

### 3) Consistency
- Shares tab eligibility matches API `/api/ui/symbol-diagnostics` response.
- No Shares content on Options tab.

### 4) Tests
- Shares tab renders Trade Plan sections and shows entry zone/stop/targets when present.
- Close position flow: modal with exit_price, exit_date, notes; after close, active removed and appears in closed (or UI updates).
- Plain-English hold-time line present on Shares Trade Plan when ATR/distance available.

### 5) Docs + verification
- `docs/releases/R23.5.0_requirements.md`, `R23.5.0_release_notes.md`.
- `out/verification/R23.5.0/notes.md` with gate commands + checklist placeholders.
- Update `chakraops/docs/releases/RELEASE_CHECKLIST.md` with R23.5.0 section.

### 6) Gates
- Frontend tests + build pass. Backend tests if backend touched.

---

## Constraints
- Minimal backend changes; backward-compatible schemas for close/history.
- UI premium and consistent with R23.4.6 accordion layout.
- No secrets in logs. No changes to Copilot behavior.
