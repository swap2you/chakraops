# R35.0 Requirements

1. Canonical job inventory with persisted run records
2. Unified scheduler disabled by default; explicit operator enablement
3. Job-level cross-process locking and bounded retries
4. Recovery of interrupted STARTED runs on startup
5. Unified notification dedupe for job failures/recovery
6. Backup/restore with manifest, temp-path validation, retention
7. Operations API and System Diagnostics panel
8. Windows startup/shutdown scripts and runbooks
9. No broker execution; Stay in Cash valid
10. Final R31–R35 handoff documentation
