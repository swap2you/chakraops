# R28.4 — Live open mirror to unified positions DB

**Branch:** release/R28.4 (operator creates)  
**Manual-only.** No broker automation.

## Goal

Mirror LIVE OPEN events into the unified positions DB so unified-open is consistent without relying only on read-only aggregation. When a live SHARES position is opened or a live OPTIONS position is opened (CSP/CC), mirror to positions_open with stable ids. Keep existing live CLOSE/ROLL mirror logic; extend reconcile health to include live-open counts; safe labels only (OK/Review).

## Non-goals

- No broker integration, no auto execution.
- No schema-breaking refactors.
- No new UI pages; only small UI changes if essential (prefer none).
- No changes to decision artifacts.

## Non-negotiables

- Decision JSON code-only; no FAIL_/WARN_ in decision artifacts.
- UI must never display raw FAIL/WARN/PASS; safe labels only.
- Runtime state and API: no raw tokens. Determinism preserved.
- Reconcile advisory: created only on write paths (open/close/roll), deduped (at most one active NEW/ACKED).

## Scope

### Backend

- **mirror_live_shares_open_to_unified(share_position)** — Idempotent upsert into positions_open with id `live_shares_{id}`; instrument_type=SHARES, is_paper=0.
- **mirror_live_open_to_unified (options)** — Already present (R28.1); id `live_options_{position_id}`. Idempotent.
- **Live shares close** — When mirroring live shares close, remove corresponding open row from positions_open (one per symbol for live SHARES).
- **get_positions_unified_reconcile_health** — Extend with: live_shares_open_count, live_options_open_count, unified_open_live_shares_count, unified_open_live_options_count. status OK or Review only.
- **Wiring** — After successful LIVE shares upsert (POST /shares/positions/{symbol}), call mirror_live_shares_open_to_unified(created) and ensure_reconcile_advisory_notification(). Options open already wired on roll.

### Tests

- test_r284_positions_unified_live_open_mirror.py: live shares open idempotent, live options open idempotent, reconcile health includes live counts and safe labels, mirror does not write decision_latest.

### Frontend

- Prefer no UI changes. System Diagnostics reconcile block may show new live-open counts; ensure no raw FAIL/WARN/PASS in DOM.

## UAT checklist

- [ ] Create a live shares position via UI/API (or fixture) → unified positions shows it as LIVE open with stable id; no duplicates on repeat.
- [ ] Create a live options open (CSP/CC, e.g. via roll) → unified positions shows LIVE open; no duplicates.
- [ ] Close/roll still results in open removed + closed inserted (idempotent).
- [ ] System Diagnostics reconcile shows OK/Review only; no raw FAIL/WARN/PASS.
- [ ] Reconcile advisory: at most one active NEW/ACKED; UI safe labels only.
