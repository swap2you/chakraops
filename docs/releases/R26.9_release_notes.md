# Release R26.9 — Execution discipline lock (Ticket → Journal → Notifications → EOD)

**Date:** 2026-02  
**Branch:** release/R26.9  
**Goal:** Enforce execution discipline: queue Mark Done only with journal or skip reason; EOD mark-done blocked when NEW notifications exist unless override. Manual-only.

---

## Scope

### Backend

- **Execution log store** — `app/core/ops/execution_log_store_r269.py`: SQLite table execution_log (id, ts, symbol, strategy, action, ticket_id, event_type, reason). event_type: MARK_DONE, SKIP_JOURNAL, EOD_OVERRIDE. DATA_DIR.
- **API** — POST /api/ui/ops/execution-log (write event); GET /api/ui/ops/execution-log?date= (list by date).
- **EOD mark-done** — When kind=EOD: if notifications_new_count > 0 and no override_reason → 409 "Cannot complete EOD while inbox has NEW items." If override_reason provided, write EOD_OVERRIDE to execution_log then checklist_set_done.

### Frontend

- **TodayPage queue** — Queue item includes ticket_id, journal_saved. Mark Done: allow if journal entry exists for today (symbol + strategy); else "Skip journal" modal → POST SKIP_JOURNAL + MARK_DONE → mark done.
- **Save to Journal** — On success from Ticket page, dispatch event so Today queue item with same ticket_id sets journal_saved=true.
- **EOD** — Mark EOD Done: if 409, show message and override reason input; retry with override_reason.
- **Badges** — "Journal saved", "Skipped (reason recorded)". No FAIL/WARN.

### Tests

- Backend: test_r269_execution_discipline.py.
- Frontend: TodayPage R26.9 (queue gate, skip modal, EOD blocked, no FAIL/WARN).
