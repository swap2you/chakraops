# Release R27.0 — Paper Trading Mode (simulated fills + P/L)

**Date:** 2026-02  
**Branch:** release/R27.0  
**Goal:** Paper execution path: simulated fills from Trade Ticket, paper positions with realized P/L, journal/reports integration with is_paper. Manual-only; CSP/CC/SHARES.

---

## Scope

### Backend

- **Paper store** — app/core/paper/paper_store_r270.py: paper_positions, paper_fills; OPEN/CLOSE; realized_pl; DATA_DIR/paper.db.
- **API** — POST /api/ui/paper/execute (OPEN creates position+fill+journal is_paper; CLOSE closes position, realized_pl, journal); GET /api/ui/paper/positions; GET /api/ui/paper/summary?month=.
- **Journal** — is_paper column (default false); journal_create(is_paper=); journal_list(include_paper=); journal_monthly_aggregate(include_paper=). GET /journal and monthly report accept include_paper query.

### Frontend

- **TradeTicketPage** — Paper execute toggle; fill inputs (price/premium, fees); "Simulate Fill" → POST paper/execute; toast + journal-saved event.
- **Paper page** — /paper; Open / Closed tabs; table (symbol, strategy, qty, open price, realized).
- **JournalPage / ReportsPage** — "Include paper" toggle; pass include_paper to API.

### Tests

- Backend: test_r270_paper_trading.py. Frontend: TradeTicketPage paper UI, Paper page, Journal/Reports include_paper, no FAIL/WARN.
