# Release R28.9 — Reconcile Diff remediation + DB-first read

**Date:** 2026-02  
**NO GIT.** Manual-only.

**Goal:** When reconcile is Review, operator can "Rebuild now" from the Reconcile Diff card and view "what is stored" (DB-only read) on Positions. No writes from DB read; safe labels only.

---

## User-visible changes

- **System Diagnostics — Reconcile Diff card (when status Review):**
  - "Rebuild now" button: confirm then runs existing rebuild (include_paper: true). Button disabled while running; details collapse on success.
  - "View DB stored positions" link to Positions with source=db.
- **Positions page:**
  - Query param **source=recompute** (default): data from GET /api/ui/positions/unified (computed from sources). Label: "Source: Computed".
  - Query param **source=db**: data from GET /api/ui/positions/unified/db (what is in SQLite). Label: "Source: Stored".

## API endpoints

- **GET /api/ui/positions/unified/db** — DB-first read. Params: state (default open), include_paper (default true), instrument_type, symbol, limit (default 500, max 2000). Returns { status, status_label, count, items }. No source recompute; no writes.

## Determinism and safe labels

- DB read: deterministic sort (symbol, instrument_type, expiry, strike, opened_ts, id). Response and UI use safe labels only; no FAIL/WARN/PASS.
- Rebuild now uses existing R28.7 rebuild; invalidation includes reconcile-diff query.
