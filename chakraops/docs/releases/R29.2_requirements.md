# R29.2 — Stored vs Computed Compare v1

**NO GIT.** Manual-only. No broker automation.

## Goal

Add a focused compare mode for a selected symbol: show Stored vs Computed positions and highlight differences with safe labels only (operator trust).

## Non-goals

- No new backend endpoints unless strictly required. No notification creation. No background jobs.

## Non-negotiables

- Decision artifacts code-only; do not write out/decision_latest.json from these paths.
- Never persist FAIL_/WARN_ or prose in decision artifacts. UI and API safe labels only.
- No FAIL/WARN/PASS in API or UI; sanitize defensively in compare display.
- Deterministic ordering preserved. Do not stage out/* runtime artifacts.

## Scope

### A) Backend

- Confirm GET /unified and GET /unified/db both support symbol and include_paper (parity). No new endpoints.
- Tests: symbol filter parity, deterministic order, no forbidden tokens in payloads, no decision_latest write.

### B) Frontend — Compare panel

- Compare panel appears only when symbol filter is set. Button "Compare stored vs computed" toggles open/closed.
- When open: Stored list (from /db), Computed list (from /unified), same symbol/include_paper; diff summary (missing_in_stored, extra_in_stored, mismatched); diff details list (Missing/Extra/Mismatch, id, instrument_type, fields_diff); all display values sanitized (no FAIL/WARN/PASS, no FAIL_/WARN_).
- Links: View diff in diagnostics (/system), Rebuild unified positions (reuse confirm modal), Switch to Computed/Stored unchanged.
- Only fetch compare data when panel is opened (enabled flag on hooks). Stable sort (match backend).

### C) Tests

- Backend: test_r292_positions_compare_contract.py (symbol parity, deterministic order, no forbidden tokens, no decision write).
- Frontend: symbol set → Compare appears; open → both APIs same params, diff summary/details; closed → no diff summary; no FAIL/WARN/PASS or FAIL_/WARN_ in document.

### D) Docs + verification

- R29.2_requirements.md, R29.2_release_notes.md; R29.2 section in RELEASE_CHECKLIST.md.
- out/verification/R29.2/notes.md: gate commands, tails, UAT, grep proof.
