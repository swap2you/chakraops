# Release R30.2 — Readiness Pack Export v1 (manual download, sanitized, deterministic)

**Date:** 2026-02  
**NO GIT.** Manual-only.

**Goal:** Add a manual "Download readiness pack" action on Trade Ticket that exports a small deterministic, sanitized ZIP bundle (readiness payload, system-health subset, notes). No persistence. No decision write.

---

## User-visible changes

- **Trade Ticket — Execution readiness card:** New button **"Download readiness pack"**. Clicking downloads a ZIP file named `readiness_pack_<symbol>_<utc_ts>.zip` containing sanitized JSON only (no forbidden tokens, no secrets).

## API / backend

- **GET /api/ui/trade-ticket/readiness-pack** — Query: symbol (required), mode (live|paper), ticket_kind (ENTRY|CLOSE|ROLL|CC), include_paper (default true). Response: application/zip with manifest.json, readiness.json, system_health_subset.json, notes.json. All content sanitized via sanitize_json_for_export; deterministic ordering. No decision_latest write.

## Tests and evidence

- Backend: test_r302_trade_ticket_readiness_pack.py — expected files in ZIP, no forbidden tokens, deterministic for fixed fixture, no decision write.
- Frontend: TradeTicketPage — Download readiness pack button; click calls downloadReadinessPack with correct args; no forbidden tokens.
- Evidence: **out/verification/R30.2/notes.md**.
