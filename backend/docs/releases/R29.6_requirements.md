# R29.6 — Integrity sample items: safe deep links (NO GIT, no decision write)

**NO GIT.** Manual-only. No broker automation, no schedulers.

## Goal

Make integrity sample items actionable: provide safe deep links so the operator can click from a sample item to Positions (and optionally Diagnostics) without manual copying. Deterministic ordering preserved; no forbidden tokens in API/UI/state.

## Non-negotiables

- Decision artifacts code-only. Do not write out/decision_latest.json from integrity-check endpoints.
- Never persist raw FAIL_/WARN_ tokens in decision artifacts or state.
- UI must never display raw FAIL/WARN/PASS or FAIL_/WARN_. Safe labels only; sanitization.
- Determinism: stable ordering for sample items (symbol, instrument_type, id).

## Scope

### Backend — positions_unified_store_r279.py

- For each integrity sample item add:
  - **link_positions_url:** `/positions?source=db&symbol=<urlencoded_symbol>&include_paper=<true|false>` (stdlib URL encoding).
  - **link_diagnostics_url:** `/system` (existing diagnostics route).
- Include link fields in: run_positions_unified_integrity_check response sample_items; state file (out/positions_unified_integrity_check_state.json); get_positions_unified_integrity_check_health last_sample_items; get_positions_unified_integrity_check_result last/history.
- Tests: test_r296_integrity_sample_links.py — links present and deterministic; no forbidden tokens in sample item JSON; GET/POST integrity-check do not create/modify out/decision_latest.json.

### Frontend

- **api/types.ts:** Extend IntegrityCheckSampleItem with link_positions_url?, link_diagnostics_url?.
- **PositionsPage.tsx / SystemDiagnosticsPage.tsx:** In sample items list, render "Open positions" (link_positions_url) and "Open diagnostics" (link_diagnostics_url) when present. Use sanitizeForDisplay; no forbidden tokens in DOM.
- Tests: PositionsPage — when sample items include link_positions_url, "Open positions" link has correct href; document has no /\b(FAIL|WARN|PASS)\b/ and no /FAIL_|WARN_/. SystemDiagnosticsPage — same for Integrity Check card sample list.
