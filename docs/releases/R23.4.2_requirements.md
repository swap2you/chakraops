# R23.4.2 — Copilot key parsing + auth diagnostics + non-500 failures

## Objectives

- Parse Copilot API key from env robustly (strip whitespace, surrounding quotes, accidental `VAR=` prefix).
- Reject malformed keys (e.g. internal spaces) with 503 and `COPILOT_KEY_MALFORMED`; never 500 for missing/malformed.
- Surface Copilot status in system-health (enabled, key_present, key_format_ok, model) for diagnostics.
- Document key configuration and error codes in release notes and runbook.

## Scope

### Part 1 — Key handling (backend)

- **COPILOT_OPENAI_API_KEY** then **OPENAI_API_KEY**; normalize: strip, strip surrounding `'`/`"`, remove `OPENAI_API_KEY=`/`COPILOT_OPENAI_API_KEY=` prefix.
- If key has internal whitespace → treat as invalid (`COPILOT_KEY_MALFORMED`), do not call OpenAI.
- **`_validate_key_format(key)`:** startswith `sk-`, length ≥ 20, no spaces/newlines/tabs; return error_code if invalid.
- **copilot_ask:** if missing → 503 `COPILOT_KEY_MISSING`; if malformed → 503 `COPILOT_KEY_MALFORMED`; auth 401 → 502 `COPILOT_AUTH_FAILED`.
- Startup log: `[COPILOT] enabled= key_present= key_format_ok= model=` (no key content).
- Unit tests: quotes/strip accepted; internal space → MALFORMED; missing → MISSING.

### Part 2 — System health

- **GET /api/ui/system-health** includes **copilot:** `{ enabled, key_present, key_format_ok, model }` (no secrets).
- Frontend (optional): Copilot panel shows “Key looks malformed…” when `key_present && !key_format_ok`; `COPILOT_KEY_MALFORMED` fix hint in banner.

### Part 3 — Docs + verification

- **R23.4.2_requirements.md**, **R23.4.2_release_notes.md**, **out/verification/R23.4.2/notes.md**.
- **RELEASE_CHECKLIST.md** updated with R23.4.2 section.
- Verification notes: gate outputs, manual steps (key with quotes/spaces, no 500, no secrets in console, grep proof for decision artifacts).

### Part 4 — Repo hygiene

- No new files under `out/` except `out/verification/R23.4.2/*`. Do not commit `.env` or secrets.

## Acceptance criteria

- Copilot never returns 500 for missing/malformed keys; uses 503/502 with clear error_code.
- Key parsing accepts common .env quoting/whitespace mistakes.
- Logs and responses contain zero secrets.
- Gates pass and are recorded in **out/verification/R23.4.2/notes.md**.
