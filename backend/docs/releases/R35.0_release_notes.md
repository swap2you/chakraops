# R35.0 Release Notes

## Operations

- New `app/core/operations` module: job registry, scheduler, executor, backup, notifications
- Operations API at `/api/operations/*`
- System Diagnostics R35 operations panel

## Scheduling

- Master scheduler and all jobs **disabled by default**
- Legacy in-process schedulers gated behind `CHAKRAOPS_LEGACY_SCHEDULERS_ENABLED=false`
- Enable requires `confirm=ENABLE` via API

## Backup

- SQLite + JSONL backup with manifest and checksum verification
- PowerShell scripts under `chakraops/scripts/` and repo `scripts/` for startup/shutdown

## Runbooks

- `RUNBOOK_STARTUP_SHUTDOWN.md`, `RUNBOOK_SCHEDULER.md`, `RUNBOOK_BACKUP_RESTORE.md`, `RUNBOOK_TROUBLESHOOTING.md`

## Tests

- 12 new `test_r350_*` modules; backend 1248 passed
