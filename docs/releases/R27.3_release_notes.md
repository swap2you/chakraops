# Release R27.3 — Live position close workflow parity + position realism

**Date:** 2026-02  
**Branch:** release/R27.3  
**Goal:** Live shares close from UI with journal entry; options close/roll record-only journaling; reports hygiene. Manual-only; no broker automation.

---

## Scope

- **Live shares close:** Extend POST /api/ui/shares/positions/{symbol}/close to support fees, ts; after close, auto-create journal entry (is_paper=false, action SELL, link_id=shares:{symbol}:{position_id}). Frontend: Close button + modal (close price, fees, ts, notes) on Shares/Portfolio; success toast; position moves to closed list.
- **Options close/roll journaling:** New endpoint or flow to record CLOSE_CSP/CLOSE_CC/ROLL in Journal (contract_key, expiry, strike, right, premium, fees, notes). No position execution. "Record close" from Trade Ticket or position lifecycle strip.
- **Reports:** Live journal entries fully populate strategy/action for monthly aggregates.
- **Tests:** test_r273_live_close_workflow.py; frontend close modal (mocked), no FAIL/WARN in DOM.
- **Docs:** R27.3_requirements.md, RELEASE_CHECKLIST, out/verification/R27.3/notes.md.
