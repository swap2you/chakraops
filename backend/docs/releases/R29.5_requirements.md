# R29.5 — Integrity remediation UX (manual-only, safe labels, deterministic)

**NO GIT.** Manual-only. No broker automation, no schedulers.

## Goal

When integrity status is Review, give the operator a single obvious sequence of actions and a quick way to copy a sanitized summary for support/debugging. Deterministic and safe-label-only.

## Non-negotiables

- Decision artifacts code-only; do not write to out/decision_latest.json. No prose or FAIL_/WARN_ in decision artifacts.
- UI must never display raw FAIL/WARN/PASS or FAIL_/WARN_. Safe labels only; sanitize displayed strings.
- Manual-only. No background jobs.

## Scope

### Frontend — PositionsPage

- When status === "Review" in Integrity section:
  - Button **"Copy remediation summary"**: copies sanitized text (no forbidden tokens). Content: heading "Unified Positions Integrity: Review", counts (missing/extra/mismatched), up to N sample items (cap 10) in API order, each line `{kind} {symbol} {instrument_type} {id} {fields_diff}`. Stable ordering (use API order).
  - Link **"Open diagnostics"** to System Diagnostics (/system).
- Tests: Copy calls navigator.clipboard.writeText with sanitized content; document has no forbidden tokens.

### Frontend — SystemDiagnosticsPage

- Under "Unified Positions Integrity Check" card:
  - If OK: show "No action needed."
  - If Review: show ordered guidance bullets (View diff details link to Positions; Run integrity check; Rebuild unified positions). Use sanitizeForDisplay for dynamic strings.
- Tests: Review renders guidance and links; no forbidden tokens in document.

### Backend

- Prefer zero changes. Existing system-health and GET integrity-check already expose safe data. No new endpoints.

### Docs + verification

- R29.5_requirements.md, R29.5_release_notes.md; R29.5 section in RELEASE_CHECKLIST.md (unchecked until evidence).
- out/verification/R29.5/notes.md: gate commands, tails, grep proof, UAT.

## UAT checklist

- [ ] Positions page shows "Copy remediation summary" only when Review.

- [ ] System Diagnostics shows remediation guidance when Review.
