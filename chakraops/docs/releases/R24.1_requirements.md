# R24.1 — Actionable Trading Workflow v1

## Non-negotiables

- Decision JSON remains code-only. No prose/UI strings/panels persisted; no raw FAIL_/WARN_ in persisted JSON.
- UI must never display raw FAIL_/WARN_ codes.
- SDLC gates recorded in `out/verification/R24.1/notes.md`.
- No new write capabilities (no broker orders). Existing positions CRUD only.

## Part 1 — Position-aware next_action

- **1.1** `next_action_code` for OPTIONS and SHARES: ENTRY (eligible, no position), HOLD (position open, not near exit), CLOSE (target/stop hit), ROLL (near DTE threshold; safe codes only), NONE.
- **1.2** Request-time `next_action_details` in symbol-diagnostics only (not persisted): `action`, `rationale_lines` (safe, plain-English), `key_numbers` (spot, t1, atr, delta_best, premium_est, dte, profit_pct when applicable).

## Part 2 — Actionable Slack message upgrade

- **2.1** Per-symbol block: symbol, strategy (CSP/CC/SHARES), next action, suggested sizing, key levels; options: contract_key/option_symbol, delta_best, dte, bid/ask/spread_pct when available.
- **2.2** Strict sanitization: no FAIL/WARN, api_key/token, local paths. Tests for required fields and forbidden substrings.
- **2.3** Dedupe: do not resend same action+contract+size within N minutes unless severity changed.

## Part 3 — Dashboard workflow polish

- **3.1** Action Needed: top 5 options + top 5 shares; each row: symbol, next action badge, 1–2 rationale lines, key number; link to symbol page with tab + accordion.
- **3.2** Recently changed: last 5 action transitions (in-memory or notifications store).

## Part 4 — Retention / out/ hygiene

- **4.1** Bounded retention: keep `decision_latest.json` + last K archived runs (configurable). Document in checklist.

## Tests and docs

- Backend: next_action_code transitions; Slack message tests (required fields, forbidden substrings, dedupe).
- Frontend: Dashboard Action Needed rows; symbol deep-link (tab/accordion).
- Docs: R24.1_requirements.md, R24.1_release_notes.md, RELEASE_CHECKLIST R24.1, out/verification/R24.1/notes.md.
