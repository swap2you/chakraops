# Simple Keywords

Use these exact phrases in the appropriate tool:

- `PROGRAM STATUS`
- `VALIDATE PROGRAM LIBRARY`
- `START R31.0`
- `CURSOR BUILD R31.0`
- `CLAUDE REVIEW R31.0`
- `CODEX REVIEW R31.0`
- `COWORK UAT R31.0`
- `READY FOR PR R31.0`
- `RECORD MERGE R31.0`
- `NEXT RELEASE`

Replace `R31.0` with `R32.0`, `R33.0`, `R34.0`, or `R35.0`.

Every tool must first read `AGENTS.md` and `docs/ai/MASTER_CONTROL.md`.
