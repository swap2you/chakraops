# Release R30.1 — Readiness: fix links + gating-aware UI (manual-only)

**Date:** 2026-02  
**NO GIT.** Manual-only.

**Goal:** Make readiness actionable without enforcing trades: per-check "Fix" links and "Ready to execute" banner with Review guidance. No hard blocking; manual-only.

---

## User-visible changes

- **Trade Ticket — Execution readiness card**
  - **Ready to execute** banner: shows "Ready to execute: OK" (green) or "Ready to execute: Review" (amber). When status is Review, a short line appears: "Resolve the items below before executing."
  - **Fix** link per check: when the backend provides an action link for a check, a "Fix" link is shown that navigates to the relevant page (e.g. positions, system, portfolio, symbol-diagnostics). No enforcement; operator can still proceed manually.

## API / backend

- **GET /api/ui/trade-ticket/readiness** — Response checks now include optional **action_label** and **action_href** (internal paths only, symbol URL-encoded where applicable). Check order and response shape unchanged. No decision_latest write.

## Tests and evidence

- Backend: test_r301_trade_ticket_readiness_actions.py — action links per check, safe tokens, no decision write, deterministic order.
- Frontend: TradeTicketPage — Fix links and hrefs, Ready to execute Review banner and guidance, no forbidden tokens.
- Evidence: **out/verification/R30.1/notes.md**.
