# Release R23.4.3 — Copilot key parsing + clear operator diagnostics

**Date:** 2026-02  
**Goal:** Reduce operator confusion when Copilot returns 401 (invalid_api_key): accurate fix hints, robust key parsing (quotes/whitespace), and system-health diagnostics (key source, last error code).

---

## Key env vars

- **COPILOT_OPENAI_API_KEY** (preferred) — used first if set and valid.
- **OPENAI_API_KEY** — fallback if COPILOT_OPENAI_API_KEY is not set or empty after cleaning.

Values are cleaned before use: leading/trailing whitespace is stripped, and surrounding single or double quotes are removed. Empty or whitespace-only values are treated as unset. Accidental pasted lines like `OPENAI_API_KEY=sk-...` are normalized (prefix stripped). Internal spaces/newlines in the key cause the key to be treated as malformed (COPILOT_KEY_MALFORMED).

---

## Quote/whitespace stripping

- **Strip whitespace** from the start and end of the env value.
- **Remove surrounding quotes** only when the value starts and ends with the same quote character (`'` or `"`). After removal, strip again.
- **Empty after cleaning** → key is considered missing (key_present can still be true if the other var is set).
- No key or fragment is ever logged or returned in API responses.

---

## System health Copilot section

**GET /api/ui/system-health** includes a **copilot** object:

| Field            | Type   | Description |
|------------------|--------|-------------|
| enabled          | bool   | True if router is mounted and key is valid. |
| key_present      | bool   | True if either env var has a non-empty value after cleaning. |
| key_format_ok    | bool   | True if key passes format checks (sk-, length, no internal spaces). |
| key_source       | string | `"COPILOT_OPENAI_API_KEY"` \| `"OPENAI_API_KEY"` \| `"NONE"`. Which var supplied the key (never the value). |
| model            | string | COPILOT_OPENAI_MODEL. |
| last_error_code  | string \| null | Last Copilot error code set on 502/503/500 (e.g. COPILOT_AUTH_FAILED). |

Use this to verify configuration without calling Copilot: e.g. after setting `COPILOT_OPENAI_API_KEY="sk-..."` in .env and restarting uvicorn, confirm `copilot.key_present === true` and `copilot.key_source === "COPILOT_OPENAI_API_KEY"`. If the key is invalid, a later Copilot request will return COPILOT_AUTH_FAILED and `last_error_code` will be set.

## UI fix hints

- **Generic:** “Set COPILOT_OPENAI_API_KEY (preferred) or OPENAI_API_KEY on the backend and restart uvicorn.”
- **COPILOT_KEY_MISSING:** “Key missing.” + generic hint.
- **COPILOT_AUTH_FAILED:** Generic hint + “Key is present but rejected by OpenAI (401).”
- **COPILOT_KEY_MALFORMED:** “Key looks malformed (quotes/spaces). Fix .env and restart.”
- No keys or stack traces are shown in the UI.
