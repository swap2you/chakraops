# Release R30.4 — In-app Readiness Pack Viewer v1 (Journal)

**Date:** 2026-02  
**NO GIT.** Manual-only.

**Goal:** Allow operator to view the readiness pack inside the app (modal) without downloading. View button on Journal when attachment exists; modal shows summary, checks with Fix links, and order stub. All content sanitized.

---

## User-visible changes

- **Journal page — Pack column:** When an entry has an attached readiness pack, **"View readiness pack"** appears in addition to "Download readiness pack". Clicking opens a modal.
- **Readiness pack modal:** Title "Readiness pack"; **Summary** (status, label, as of time); **Checks** table (code, status, label, detail, Fix link when available); **Order stub** (preformatted lines). Close button. Loading and error states with safe messages.

## API / backend

- No new endpoints. Existing GET /api/ui/journal/entry/{id}/attachment/readiness-pack returns the JSON bundle expected by the viewer (manifest, readiness with checks and order_stub, system_health_subset, notes). Optional backend tests in test_r304_readiness_pack_view_contract.py.

## Tests and evidence

- Backend: test_r304_* — attachment returns expected keys; no forbidden tokens; no decision write.
- Frontend: JournalPage — View button; modal content; no forbidden tokens; Fix links. Evidence: out/verification/R30.4/notes.md.
